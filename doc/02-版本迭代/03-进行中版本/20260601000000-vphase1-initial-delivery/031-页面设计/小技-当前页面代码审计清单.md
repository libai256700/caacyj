## 审计口径

- 以 `code/develop/yunjikeji/src/pages.json` 中当前注册的页面为准。

### 高保真生成与验收标准

- 设计目标为 390 x 844（19.5:9）；实际生成验收基准统一采用已选首页的原始规格 `853 x 1844`（宽高比约 0.4626）。
- 每张图必须原生输出为 `853 x 1844`。不得通过 CSS、图片编辑或画布后处理裁切、拉伸、压缩来伪造统一比例；输出不是该规格时，直接重生成。
- 所有页面以已选登录页、首页和底部导航组件作为统一视觉语言参考：明亮象牙白纸纹、真实白色无人机与训练物件、暖橙主操作、克制立体阴影和可读的珠光白面板。
- 是否使用场景背景必须由页面业务决定，而不是所有页面默认添加。登录、绑定手机号等情境页可使用与业务相关的写实场景；组织绑定、协议、记录、查询、审核等信息密度页面默认不使用场景背景，仅保留干净的象牙白纸纹和克制材质层次。组织绑定页应直接以“搜索 + 企业列表 + 状态 + 操作”为页面主体，不得追加底部训练或无人机场景。任何背景物件不得压迫、遮挡或与前景文字重叠。
- 同一层级面板必须使用一致的左右边界；辅助身份卡不能比主表单更窄。次要背景场景必须内收并留白，视觉重量低于主交互区。
- 使用场景时，场景型背景必须作为有明确边界的独立内容带呈现，且与主表单共用左右边界；不得以整页满宽背景方式铺开，避免形成臃肿、失焦的视觉重量。

### 全量高保真交付目标与强制检查

- 交付范围为本清单中的全部有效业务页面；启动分流页不制作独立视觉图。每个业务页面在交接 HTML 中必须拥有一张高保真图，并明确标记为“待审核”或“已通过”。
- 每张图在归档前必须逐项检查：原始输出尺寸为 `853 x 1844`；橘子海暖橙为主调、象牙白纸纹与珠光白材质为基础、深海蓝文字用于可读性；不使用沉重黑底、满屏炫酷光效、杂色卡通图标或管理后台式平铺界面。
- 页面主体、名称、文案、字段、操作和状态必须以当前前端代码及接口响应为唯一依据。静态代码可确认的内容可直接使用；接口驱动字段必须主动通过测试环境、测试账号或后端测试数据取得后再绘制。无法获得动态值时，不得虚构数值、训练规则、题目、组织或业务结果。
- 背景与辅助元素必须同时符合产品定位（无人机教育、考试训练）和当前页面功能定位。抽象、低对比、无具体文字的底纹/象形层可与文字重叠或满宽出现，但不得影响阅读；任何具象实物、写实场景或具体训练物件必须内收为独立内容带，并与主内容列共用左右边界，不得满屏铺开或压迫文字。
- 信息密度页面（组织、协议、记录、查询、审核、列表）默认不使用具象场景；情境、确认、答题、引导页面可按功能使用内收的写实学习或训练物件。是否使用背景由页面内容决定，不得为了统一视觉而强行添加。
- 视觉检查还包括：所有文字可读且不重叠；长文本有合理换行；按钮、导航和列表层级清晰；页面不出现未在代码中定义的功能、不可达操作或与当前页面无关的装饰主体。
- 后续页面按当前代码审计清单批量生成，采用并发生成与逐张尺寸校验；启动分流页不制作独立高保真图。
