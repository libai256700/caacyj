# DEV-031 APP独立新首页样式改造

## 实施标准

1. 先盘点当前 APP 首页、登录页、页面注册配置、底部导航、图标与业务入口；在任务产出中记录实际复用项、不能直接复用项及原因。
2. 新首页必须使用新页面文件承载，旧首页页面文件保持不变；仅允许通过最小页面注册或入口配置把新首页设为当前入口，并确保配置可以快速切回旧首页。
3. 整体构图严格参考 2026-07-18 用户图一，只把蓝色体系替换为登录页暖橙、浅粉、柔黄与米白体系；顶部欢迎区保留紧凑标题、副标题和右侧猫头鹰，不得继续使用上一轮大字号多行标题和分散卡片结构。
4. 第一块固定为白色“测评”面板，对应参考图“AI创作”：面板边缘、内边距、标题/副标题字号与层级、卡片间距须贴合参考图；内容固定采用左侧一张纵向大卡“自我评测”，右侧两张横向叠放小卡“考题测评”“错题重做”。三张卡均必须有大面积主题插画，允许复用项目图标并通过多层 CSS 装饰组合成插画，但不能只剩单个小图标、纯色块或文字；卡片分别采用暖粉、暖黄/橙、浅绿或与登录页协调的柔和渐变。
5. 第二块固定为白色“常用功能”面板，沿用第一块的标题、边缘、内边距和渐变卡片语言；内部仅放“岗位招聘”“联系客服”两个完整功能块，每块均须有标题、副标题、独立的大面积主题插画和可点击区域，颜色与渐变由实现选择但必须与登录页暖色基线协调。
6. 底部导航固定为三个等宽入口“首页 / AI工作台 / 我的”，白色底栏高度、标签字号、图标尺寸、选中/未选中颜色和上下间距须贴合用户图三；中间 AI 工作台使用登录页猫头鹰正式资产，圆形主体明显大于左右图标并向上悬浮，带白色外圈与暖色阴影，不得使用上一轮普通等高图标布局。
7. 新首页不得修改现有登录逻辑、练习业务逻辑、招聘数据机制、客服机制、AI 工作台逻辑或我的页面业务逻辑；“自我评测 / 考题测评 / 错题重做 / 岗位招聘 / 联系客服”必须复用项目真实入口，不新造接口或假结果。
8. `360x800`、`390x844`、`430x932` 三档视口不得出现元素重叠、文案裁切、横向滚动、底部导航遮挡或安全区冲突；三档截图必须同时包含完整第一块、第二块主要内容和底栏，视觉判定不得低于 `95/pass` 且不得存在缺失元素类差异。
9. 不修改 `uni_modules/**`；不得覆盖或回退用户当前工作区已有修改。
