# DEV-030 APP登录页样式改造

## 实施标准

1. 正式实现入口为 `code/develop/yunjikeji/src/pages/auth/login.vue`，范围仅限现有 APP 登录页的视觉样式、颜色和为构图服务的展示结构调整。
2. 严格复刻参考图的布局、层次和渐变表现，仅将紫色体系替换为项目现有暖色体系：页面顶部为全宽暖色渐变欢迎区，吉祥物不得带白色圆框；白色表单以不对称曲线与欢迎区叠层并延伸至页面底部。
3. 品牌标题固定为“云技科技”，副标题保留；表单顶部为“学员 / 企业”两个纯文字标题式 Tab，不使用胶囊、分段控件外框或按钮底；字段使用“账号”“验证码”独立标签，第二字段可见占位文案为“请输入验证码”，右侧“获取验证码”仅作不可点击展示；输入框不得显示手机、盾牌等前缀图标。
4. 主按钮按参考图尺寸与位置使用项目暖色水平渐变；底部按参考图保留“第三方登录”标题，并只展示两个独立圆形图标：微信可继续原有登录交互，iOS 仅展示且不得添加 `button`、`@tap`、导航、请求或新 handler。
5. 页面必须可见品牌、副标题、学员、企业、账号、验证码、请输入手机号、请输入验证码、获取验证码、登录、第三方登录、协议和 ICP；不得出现“密码”或“请输入密码”。“获取验证码”不得绑定按钮、点击、倒计时、短信请求或 handler。
6. `390×844` 视口几何容差：面板左顶 `y=196~204`；两个输入框均为 `x=35~43`、宽 `308~316`、高 `47~53`，首框 `y=299~307`、次框 `y=407~415`；登录按钮 `y=496~504`、高 `50~54`；协议区 `y=574~590`；第三方登录标题 `y=710~728`；微信/iOS 图标 `y=740~784`。
7. `360×800`、`390×844`、`430×932` 均不得出现元素重叠、文案裁切、横向滚动或安全区遮挡。
8. `script setup` 与本轮返工前 HEAD 完全一致；`selectLoginRole`、`handleLogin`、`handleWechatLogin`、内部 `verifyCode` / password 校验和提交、协议跳转、加载态及登录后分流保持不变；本任务不新增验证码请求、倒计时、接口、数据表、状态映射、日志或配置。
9. 不修改 `uni_modules/**`；不得用假数据替代现有真实登录机制。
