# AC-PUSH-001 管理端创建与发布消息

- 类型：业务-交互级
- 前置条件：管理平台已登录具备消息管理权限的运营或管理员账号；进入现有消息中心下的 `App 推送管理`。
- 业务起点：运营需要向学员端、企业端或指定受众发布一条正式系统消息。
- 触发动作：创建消息草稿，填写标题、摘要、正文、受众、发送方式、发送时间和跳转目标后执行保存或发布。
- 关键交互：消息可在草稿态编辑；发布前可复核受众范围与跳转配置；发布后可在详情页查看消息内容、受众快照和当前发送状态。
- 业务终点：管理平台形成一条正式的 App 推送记录，并具备后续统计、取消或明细追踪入口。
- 通过条件：消息中心下存在独立 `App 推送管理` 能力；消息创建、编辑、发布链路完整；受众快照与消息详情可回看；不复用客服会话入口冒充运营推送。
- 核对方式：管理平台页面真实操作、消息详情回看和消息状态核对。
- 证据承接：`061-验收标准/03-测试验证/` 中后续管理端页面、接口和状态证据。
