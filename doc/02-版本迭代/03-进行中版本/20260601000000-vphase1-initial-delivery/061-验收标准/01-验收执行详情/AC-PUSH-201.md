# AC-PUSH-201 四表数据承接与状态审计

- 类型：技术-数据级
- 正式入口：消息主表、收件人表、设备表和投递表，以及与之对应的状态查询和审计结果承接入口。
- 支撑结果：同一条消息可追到正文、受众快照、主体键、设备绑定、投递结果、失败原因、点击时间和已读时间，便于统计、排错和复核。
- 数据边界：至少包含 `yj_push_message`、`yj_push_recipient`、`yj_push_device`、`yj_push_delivery` 四类核心记录；收件人主键必须体现 `subject_type + subject_id + tenant_id`；取消发送、失败重试和历史投递结果必须保留审计痕迹。
- 通过条件：四类记录能完整串联消息创建、受众快照、设备绑定、逐设备投递、点击上报和已读回写；历史取消和失败重试不物理抹除业务痕迹；统计结果可从正式数据记录回溯。
- 证据承接：后续数据库脚本、测试库验证、日志回写和状态抽样核对证据统一回写 `061-验收标准/03-测试验证/`。
