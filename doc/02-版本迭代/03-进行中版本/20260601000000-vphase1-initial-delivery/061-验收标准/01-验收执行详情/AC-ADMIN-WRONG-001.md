# AC-ADMIN-WRONG-001 后台错题管理列表展示与查询承接

- 类型：业务-交互级
- 关联任务：`DEV-011`
- 正式入口：`/yj/practice/wrong-question` 页面与后台资源 `practice-record-detail`。
- 业务起点：管理员进入后台错题管理页并看到当前错题列表。
- 触发动作：输入分类名称、题干或是否正确条件，切换分页，点击详情按钮。
- 关键交互：列表中原“练习记录”列展示为“练习时间 + 分类名称”，原“题目编号”列展示为当前题目题干；页面进入时“是否正确”默认选中“否”，首个列表请求必须携带 `is_correct=false`，且默认只展示是否正确为否的答题明细；点击重置后也恢复为“否”并重新按 `false` 查询。“是否正确”下拉仍固定提供 `不限 / 是 / 否`，其中用户主动选择“不限”时不传或清空 `is_correct`，详情按钮继续按行 `id` 工作，`record_id` / `exercises_id` 仅保留为内部关联字段，不再作为列表列或查询条件。
- 业务终点：管理员可按真实分类、题干和正确性定位错题，并从列表进入明细查看，不再依赖题目编号作为页面主要展示字段。
- 结果承接：历史题干按题目主表当前值展示，不按作答快照回显。
- 核对方式：浏览器交互验证列表列名、筛选条件、分页切换和详情按钮；三档视口都保持一致。
