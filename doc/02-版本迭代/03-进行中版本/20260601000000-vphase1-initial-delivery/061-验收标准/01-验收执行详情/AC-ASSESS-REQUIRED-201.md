# AC-ASSESS-REQUIRED-201 自测题库是否必填数据承接

- 类型：技术-数据级
- 关联任务：`DEV-084`、`DEV-085`
- 正式入口：`yj_practice_exercises.is_required`。
- 支撑的业务结果：页面保存“是 / 否”后刷新和再次编辑仍得到一致结果。
- 技术边界：复用现有 `bit(1)` 字段及默认必填语义，不新增、删除或修改数据库结构，不操作生产数据库。
- 通过条件：选择“是”持久化为 1，选择“否”持久化为 0；分页和详情回读与保存结果一致；本次更新不覆盖题干、题型、状态、排序、步骤和答案数据。
- 证据承接方式：测试环境接口前后回读与只读数据核对记录写入正式测试验证目录。
