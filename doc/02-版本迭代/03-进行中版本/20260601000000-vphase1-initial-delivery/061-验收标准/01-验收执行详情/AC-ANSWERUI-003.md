# AC-ANSWERUI-003 动态进度与末题语义

- 类型：业务-交互级
- 业务起点：练习接口返回当前索引、总题数和当前题目，提交接口返回下一题索引或完成状态。
- 触发动作：用户在普通题、上一题、末题或答题结果状态中操作底部按钮。
- 关键交互：题头显示 `currentIndex + 1 / totalQuestions`，进度线按真实百分比更新；普通题显示当前可用动作，末题显示提交或完成语义，错误结果显示下一题动作。
- 业务终点：不存在硬编码 `1/12`，末题不会错误跳转到不存在题目，普通题不会提前显示完成。
- 结果承接：当前索引、总题数、结果完成标记和下一题索引均沿用现有响应映射。
- 核对方式：Playwright 用确定性视觉夹具分别返回普通题和末题数据，检查显示文本、按钮组合、提交请求与完成请求。

- 当前状态：已通过（独立验收）。
- 独立验收结果：三档均验证 `1/12`、`5/12`、`12/12` 动态题号；普通题、有上一题和末题语义正确，上一题请求真实 `index=10` 且选中态计数为 `0`。
- 证据承接：`../03-测试验证/DEV-038/`。
