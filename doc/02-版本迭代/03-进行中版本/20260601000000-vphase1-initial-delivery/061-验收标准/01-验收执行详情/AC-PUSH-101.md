# AC-PUSH-101 管理端与 APP 消息接口契约

- 类型：技术-接口级
- 正式入口：管理平台消息管理接口、APP 消息列表/详情/未读数接口、已读回写接口、点击上报接口以及发布/取消接口。
- 支撑结果：管理平台可创建、发布和取消消息；APP 可读取当前主体消息、查看详情并上报已读与点击；管理端与 APP 通过同一消息主数据承接状态。
- 技术边界：接口契约必须明确区分管理端操作入口与 APP 查询入口；管理端不得直接下发任意 URL；APP 只按 `messageId`、`routeKey`、`businessType`、`businessId` 等受控业务键承接。
- 通过条件：草稿保存、发布、取消、分页查询、详情查询、未读数、已读回写和点击上报接口齐全；返回结构能支撑管理端状态展示和 APP 消息中心展示；越权租户或越权主体请求被拒绝。
- 证据承接：后续接口文档、联调记录、自动化测试或接口执行证据统一回写 `061-验收标准/03-测试验证/`。
