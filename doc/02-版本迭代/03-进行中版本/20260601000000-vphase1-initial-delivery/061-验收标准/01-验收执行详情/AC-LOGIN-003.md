# AC-LOGIN-003 登录页响应式适配

- 当前状态：通过（2026-07-17 独立复验：三档视口无横向滚动、重叠、文案裁切或浏览器错误，底部圆角与留白可见）。

- 类型：业务-交互级
- 关联任务：`DEV-030`
- 业务起点：用户在不同尺寸手机视口进入 APP 登录页。
- 触发动作：在 `360×800`、`390×844` 和 `430×932` 视口下浏览并操作登录页。
- 关键交互：滚动页面、切换角色、聚焦输入框、勾选协议和触发各登录入口。
- 业务终点：全部页面元素可见、可读、可触达。
- 结果承接：保留既有主体几何；白色页面底部大圆角及外部暖色留白在三档视口内可见；`360×800`、`390×844`、`430×932` 均无元素重叠、文案裁切、横向滚动或安全区遮挡。
- 核对方式：Playwright 驱动本机 Chrome 对三档视口执行截图、边界框、`scrollWidth`、重叠、裁切和安全区检查；证据回写 `../03-测试验证/`。
