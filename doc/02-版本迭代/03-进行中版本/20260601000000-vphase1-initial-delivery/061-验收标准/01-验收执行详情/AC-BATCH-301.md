# AC-BATCH-301 集合式插入与重排边界

- 类型：技术-代码级
- 正式入口：模式 2-5 的批次生成实现、题目排序逻辑和答案排序逻辑。
- 支撑的业务结果：批次生成更快，题目与答案顺序仍正确，模式 1 和模式 4 规则不回退。
- 技术边界：Java 侧 `orderedExercises` 决定最终题序；题目批次和答案批次分别只做一次集合式 `INSERT ... SELECT`；不再对题目批次做二次重排 `UPDATE`；`answer_code` 依据最终 `sort_no` 生成；不修改 `uni_modules/**`。
- 通过条件：SQL 次数减少且逻辑可读；题目 / 答案映射稳定；相关构建、类型检查和必要回归测试通过。
- 证据承接：`061-验收标准/03-测试验证/DEV-063/`。
