# AC-ASSESSMENT-SAVE-001 双评测保存中提示与原流程保护

- 类型：业务-交互级
- 业务起点：首页原“开始评测”入口弹出双评测选择层，用户选择“自我评测”或“职业规划评测”。
- 触发动作：前端先查询所选分类最新批次保存状态；分类13只看分类13，分类14只看分类14。
- 关键交互：`status=1` 时复用“是否需要重新测评”弹窗的视觉样式，文案固定为“上次评测正在初始化分析，请稍后”；确认、关闭、取消或点击遮罩均只关闭本提示，不调用原重测 resolver，不触发 reset、start、后续查询或导航。`status=0/2` 时继续所选分类原 completed/restart/reset/start/navigation 判断，禁止把2直接当作完成。
- 业务终点：保存中的上次评测不会被误重置、重复启动或错误跳转；未开始或写入流程已结束的批次仍交由原业务状态与原流程判断。状态2不能显示为已完成，原 `is_completed` 判断及行为必须保持不变。
- 结果承接：提示状态来自真实 latest-status 与 `yj_practice_catalog_batch.status`，不得以前端假状态、计时器或报告状态替代。
- 核对方式：测试环境分别构造分类13/14的0、1、2状态及失败补偿置2场景，核对提示文案、弹窗样式、关闭动作和网络/导航副作用；同时验证补偿前后 `is_completed` 数据未被 DEV-078 改动、状态2不被误判完成、另一分类的状态不会串用。
- 当前状态：通过（独立验收）；DEV-078整体待用户审核。
