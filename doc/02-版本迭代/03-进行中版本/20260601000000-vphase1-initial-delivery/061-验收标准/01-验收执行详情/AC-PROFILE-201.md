# AC-PROFILE-201 租户内用户与部门关联

- 类型：技术-数据级
- 正式入口：当前 `CompanyAccountFrontDO.tenantId + username(登录手机号)`、`AdminUserDO.mobile/nickname/deptId` 与 `DeptDO.id/name` 的只读关联。
- 支撑的业务结果：页面姓名和所属组织来自同一后台用户，且不会读取其他租户的同手机号记录。
- 技术边界：用户查询必须运行于当前账号 tenantId 的租户上下文；部门查询必须复用同一租户上下文和该用户 `deptId`。不新增/修改数据库表或数据，不执行 SQL 脚本，不以租户名称、地域或岗位名称代替部门。
- 通过条件：当前租户同手机号唯一用户提供 `nickname`，其 `deptId` 唯一部门提供 `deptName`；构造其他租户同手机号样本时响应不取其他租户值；缺失关联返回受控空值且数据库前后无写入变化。
- 证据承接方式：自动化租户隔离测试、测试环境只读数据核对摘要和数据库零写入检查；敏感手机号证据按规则脱敏保存。
