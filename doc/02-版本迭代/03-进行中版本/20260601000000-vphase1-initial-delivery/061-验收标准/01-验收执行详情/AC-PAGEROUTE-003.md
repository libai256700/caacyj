# AC-PAGEROUTE-003 学员首页身份门禁与三入口保持

- 类型：业务-交互级
- 业务起点：学员或企业有效会话进入 `/pages/home`。
- 触发动作：学员查看首页并操作“首页 / AI助手 / 我的”三入口及现有业务卡片；企业通过冷启动、旧缓存或历史链接误入该页。
- 关键交互：首页先执行登录和身份门禁；学员保持既有三入口、卡片文案、布局和真实导航，企业立即重启到 `/pages/service/customer-service`。
- 业务终点：学员首页仍为学员正式默认首页；企业不渲染学员自测、题库训练和错题练习；未接回 `AppDynamicTabBar` 旧四项。
- 结果承接：使用既有 `loginIdentity` 和会话事实进行身份分流，学员首页既有 `navigateTo/reLaunch` 路由映射保持不变。
- 核对方式：Playwright 分别使用学员和企业身份夹具，核对页面元素、身份跳转、入口路由和 `AppDynamicTabBar` 不存在性。
