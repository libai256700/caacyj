# AC-PUSH-301 独立 Maven 模块与回归边界

- 类型：技术-代码级
- 正式入口：后端独立通知模块、管理平台消息管理白名单改动、APP 消息中心与推送生命周期白名单改动，以及对应的编译、构建和回归检查入口。
- 支撑结果：消息通知域以独立模块承接，前后台改动边界清晰，后续开发、测试和回归可以按模块收口。
- 回归边界：后端必须以独立 Maven 模块承接消息通知域；管理端改动限定在消息管理相关页面与接口；APP 改动限定在消息中心、通知承接、设备生命周期和白名单路由；不得修改 `uni_modules/**`，不得把客服即时通讯改造成运营推送。
- 通过条件：独立模块存在且能被项目正式依赖；管理端、APP、后端改动边界可审计；相关编译/构建与差异检查通过；客服链路、H5 非本次范围和三方包边界未被破坏。
- 证据承接：后续模块编译结果、前后端构建结果、白名单差异检查和回归测试证据统一回写 `061-验收标准/03-测试验证/`。
