# AC-ADMIN-WRONG-101 后台错题管理接口契约与同口径查询

- 类型：技术-接口级
- 关联任务：`DEV-011`
- 正式入口：`GET /admin-api/practice/user-practice-exercises-record/detail/page`、`GET /admin-api/practice/user-practice-exercises-record/detail/get?id={id}`。
- 支撑的业务结果：错题管理页既能分页查询列表，也能按行 `id` 打开详情，且列表总数与当前页结果使用同一过滤口径。
- 技术边界：查询参数只承接分类名称、题干、是否正确、学员、答案、练习时间等正式条件；`record_id` / `exercises_id` 只作为内部关联或详情数据，不再暴露为列表展示字段或主要筛选条件；`is_correct` 对应前端 `不限 / 是 / 否` 三态，页面首次进入和重置后都默认以 `false` 发起查询，“不限”必须清空或省略该参数，后端不得因此追加 `d.is_correct = ?`。
- 通过条件：`COUNT` 与列表对同一条件返回一致结果；页面首次进入时默认携带 `is_correct=false` 并只展示是否正确为否的答题明细，重置后同样恢复为 `false`；“练习记录”按分类名称模糊查询；“题目”按题干模糊查询；“是否正确”为 `不限` 时不加 `is_correct` 条件，选择 `是/否` 时按真实布尔值查询；详情按钮继续按行 `id` 查询明细。
- 证据承接方式：后端聚焦测试回写 `061-验收标准/03-测试验证/DEV-011/`，并在接口记录中保留请求参数、返回列名与总数一致性证据。
