# AC-HOME-001 首页结构与风格

- 当前状态：未通过，等待按 2026-07-18 最新参考图返工。
- 类型：业务-交互级
- 关联任务：`DEV-031`
- 业务起点：学员进入 APP 首页。
- 触发动作：查看首页首屏并向下浏览主要内容块。
- 关键交互：识别紧凑欢迎区、白色“测评”面板和白色“常用功能”面板，点击五个功能入口。
- 业务终点：首页以与参考图一致的块状层级承接测评、练习、招聘和客服需求。
- 结果承接：测评面板必须采用左侧纵向大卡“自我评测”与右侧上下两张小卡“考题测评 / 错题重做”；常用功能面板包含“岗位招聘 / 联系客服”。五张功能卡均有标题、副标题、完整边缘、统一内外边距和主题配图，不能只用小图标或纯文字；整体仅将参考蓝色替换为登录页暖色体系。
- 核对方式：Playwright 三档截图与最新参考图逐项核对面板几何、卡片比例、字体、边缘、间距、渐变和配图完整性；证据回写 `../03-测试验证/DEV-031/`。
