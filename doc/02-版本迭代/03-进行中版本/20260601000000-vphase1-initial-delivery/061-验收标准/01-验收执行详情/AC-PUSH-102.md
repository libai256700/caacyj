# AC-PUSH-102 设备生命周期、可靠投递与白名单路由

- 类型：技术-接口级
- 正式入口：APP 设备注册/换绑/停用入口、后端投递任务入口、推送回调或结果处理入口、通知点击路由白名单和 APP 启动承接入口。
- 支撑结果：用户登录后设备绑定生效；退出、换绑和失效后旧绑定停用；推送与站内消息形成“双通道承接”；通知点击可安全进入白名单业务页。
- 技术边界：站内消息落库不能依赖单次离线推送成功；推送载荷只允许携带受控业务键；无白名单路由时必须回退到消息详情页；不得通过任意 URL 或任意脚本参数开放跳转。
- 通过条件：设备注册、换绑、停用、失效清理和投递重试具备正式入口；离线推送失败时消息仍能在站内消息中心看到；通知点击只进入白名单内页面；旧设备或旧账号不会继续承接新消息。
- 证据承接：后续设备生命周期脚本、推送联调记录、回调日志和通知点击验证证据统一回写 `061-验收标准/03-测试验证/`。
