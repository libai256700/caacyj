# AC-ASSESSMENT-AI-201 数据库模板与报告记录一致性

- 类型：技术-数据级
- 正式入口：自测智能体配置查询、自测结果记录写入与报告详情查询。
- 支撑结果：报告正文由当前数据库模板和本次真实测评数据共同生成，查看入口不会串用其他记录。
- 通过条件：系统提示词运行时查询数据库 `yj_agent_info.id=2.prompt_config`，版本正向 DML 必须能从真实直接前驱（`2440` 个 Unicode 码点、`6243` 个 UTF-8 字节、SHA-256 `974ef05f4cda6fe0e07d6076c06e0c87b33986461dcaf2d39feda7c1e2d8d414`）安全升级到当前 V3 提示词（`2627` 个 Unicode 码点、`6770` 个 UTF-8 字节、SHA-256 `3f2a53619b12ea47e94978d47aff1028781ea52903fe2e845362027f8160dbc1`）且可重复执行；回滚必须恢复该真实直接前驱。脚本独立验收通过后，执行人必须按开发中心正式测试库连接先备份 `id=2` 完整目标行，再执行正向 DML，并生成包含影响行数、`2627 / 6770` 和完整哈希的实际回执；生产库禁止直接执行。提示词和 Java 用户提示共同把默认 8 章、动态 A-G、AI 正文 2500-3800 Unicode 码点、确定性事实和禁止字段作为生成目标；后端对正文分数、等级、标题/章节、字数、训练、金额、证书和方向等偏差仅记录审计，不阻断持久化，评分仪表盘等固定区块始终以后端规则引擎结果为准。AI 返回和映射成功、正文 HTML 标签/属性/结构安全、固定区块组装成功且记录可持久化后，记录可从 `PENDING` 条件更新为 `SUCCESS` 并由详情接口返回；AI 调用或超时、响应映射、不安全 HTML/结构、固定区块组装或持久化失败必须进入 `FAILED`，数据库不得新增简版或阶段报告；历史简版记录由详情接口判为报告不可用。`2284 / 5809 / d7794b51...` 是更早证书阶段，`4285 / 9305 / c8f4803d...` 是更早六章历史，均不得冒充当前直接前驱。
- 证据承接：模板哈希、记录 ID、字段长度、占位符检查和详情接口一致性结果统一回写 `061-验收标准/03-测试验证/DEV-049/`。
