# AC-CAREER-ASSESS-001 首页原入口点击后的评测与报告选择

- 类型：业务-交互级
- 业务起点：首页继续只保留原有单个“开始评测”按钮和原有单个“评测结果/自测报告”入口，不在首页常驻并列展示新增选项。
- 触发动作：点击原“开始评测”后才在当前首页弹出“自我评测 / 职业规划评测”选择层；点击原“评测结果/自测报告”后才弹出“自我评测报告 / 职业规划评测报告”选择层，不跳转独立选择页面。
- 关键交互：层内“自我评测”完整调用修改前 `startSelfTest`；层内“自我评测报告”完整调用修改前 `openLatestSelfTestReport`；两个职业规划选项分别进入分类14答题和报告。职业规划答题必须承接源 `formVersion=2` 六组数据语义，不能执行分类13选填放行或报告规则。关闭、取消或点击遮罩均不得触发查询、导航、重试、重置或其他业务动作。
- 业务终点：用户进入所选评测或所选报告，页面名称、题目、完成状态和结果类型一致；分类13原提示、跳转、空状态、失败和重试行为无变化。
- 结果承接：使用真实首页、真实接口、真实题库和真实报告，不使用假状态、假题或前端硬编码结果。
- 核对方式：测试环境覆盖两个原单入口、点击后出现的两层选择、四个层内选项、关闭/取消、分类13调用序列基线对比、分类14有/无报告状态和常用移动视口。
- 当前状态：待执行。
