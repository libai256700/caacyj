# AC-ASSESS-REQUIRED-001 后台自测题库是否必填展示与编辑

- 类型：业务-交互级
- 关联任务：`DEV-084`、`DEV-085`
- 正式入口：`/yj/assessment/question`。
- 业务起点：管理员进入自测题库管理页并看到题目列表。
- 触发动作：查看“是否必填”列，打开一条题目编辑弹窗，切换“是 / 否”并保存、刷新、再次编辑；另行打开新增弹窗。
- 关键交互：列表逐行以“是 / 否”显示必填状态；编辑下拉回显该题真实值且允许切换；新增默认“是”；保存过程继续复用原提示与弹窗行为。
- 业务终点：管理员可从列表识别每题是否必填，并能在新增/编辑弹窗中可靠维护该属性。
- 结果承接：保存刷新及再次打开编辑弹窗后仍显示新值；状态、题型、自测答案、删除等原操作不回归。
- 核对方式：在本地页面完成功能自检，并由独立验收代理使用 Playwright 复跑关键交互；正式集成验收仅在测试环境执行。
