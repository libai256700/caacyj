# AC-CS-106 H5 键盘能力保护与回归边界

- 类型：技术-代码级
- 正式入口：企业端学员分页列表的页码状态、前后页控件、当前页数据和点击上下文，以及双身份客服会话页的键盘高度监听注册 / 清理、历史加载和消息发送相关目标测试。
- 支撑的业务结果：企业端 H5 可按 `pageSize=50` 浏览 101 人三页并从任意页进入正确学员会话；企业端与学员端 H5 均可正常进入和离开目标会话，历史与发送链路不被键盘能力异常中断。
- 技术边界：键盘 API 调用前进行真实能力保护；分页保持 `pageSize=50`、`pageNo=1/2/3`、首末页禁用、当前页响应替换和所选行真实双键，不得一次自动加载全部或跨页混用数据；学员端既有接口与非 H5 逻辑不回退，`uni_modules/**` 零改动。
- 通过条件：数量为 101 人时下一页可见且可操作，三页、首中末页控件状态、页码请求、数据隔离与任意页点击参数正确；目标测试、类型检查、H5 构建、差异白名单、非 H5 保护和禁区检查通过，双身份页面无键盘 API TypeError。
- 证据承接方式：DEV-028 红绿灯回执、构建与类型检查结果、仅由 `chrome-devtools-mcp` 形成的三页控件 / 网络请求 / 行数据 / 任意页点击上下文与页面错误记录、平台保护回归结果、最终差异清单和独立验收结论。
