# TC-JOBENTERPRISE-001 岗位详情企业绑定门禁

- 对应验收项：`AC-JOBENTERPRISE-001`、`AC-JOBENTERPRISE-101`。
- 测试入口：H5 真实 `src/pages/jobs.vue`，Playwright route 仅提供确定性岗位列表与 `GET /app-api/yj/student-audit/my` 响应。
- 前置条件：已登录学员会话；岗位列表包含有效 HTTPS、需补协议和无效详情链接。
- 自动化脚本：`dev061-job-enterprise-gate.spec.cjs`。

## 场景

| 场景 | 预期结果 |
| --- | --- |
| 审核结果为 `null` 或非 `2` | 原外链调用为 0；页面只显示一个正式绑定组件 |
| 审核请求延迟且快速双击 | pending 期间审核请求仅 1 次；响应后组件实例仅 1 个 |
| 绑定组件已显示后再次点击详情 | 不新增请求，不叠加组件 |
| 审核结果为 `2` | 不显示绑定组件；原 URL 和 App/H5/剪贴板分支保持 |
| 详情 URL 无效且审核结果为 `2` | 保留“暂无岗位详情链接”提示，不执行外链 |
| 审核接口返回 500 | 失败关闭：不执行外链、不伪造组件，显示错误提示 |
| 关闭、客服、绑定 | `cancel/close` 关闭；客服和绑定进入指定原生页面 |
| 360x800、390x844、430x932 | 弹框无横向溢出、无视口外裁切 |
| 源码契约 | 页面直接导入正式组件和 service；模板仅一个实例；监听 `cancel/close/service/bind` |

## 分层说明

- 接口级：由 Playwright route 校验审核接口请求次数与状态映射。
- 数据级：无数据库写入；审核夹具只作为浏览器请求响应，不写应用源码。
- 交互级：驱动真实岗位页、正式绑定组件和页面导航状态。
