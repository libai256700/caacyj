## 8. 失败判定

- 任一现有元素、业务逻辑入口或图片缺失；协议控件点击后状态未切换、勾号不可见、勾号不是黑色/等效近黑色、白底被改色，或学员/企业两种角色显示不一致。
- 文案、标签计算样式、暖色渐变、虚化层级、底部大圆角或参考构图不符；任一状态下两侧最终可见区域宽差超过 `1px`、偏离容器中线、文案中心偏离 `25%/75%` 或产生横向溢出；未选中虚化层未越过中线并下穿白色圆弧，中线 `gap` 或可见 `seam` 大于 `0px`，出现透明空隙、未虚化竖带、硬竖线或背景断层；选中 Tab 出现虚化、未选中 Tab 没有半透明虚化、切换后左右表面、虚化下穿关系或圆弧未镜像互换，或出现描边小 Tab / 胶囊；出现密码展示文案、可交互获取验证码、短信逻辑、字段前缀图标、横向微信按钮、可交互 iOS、横向滚动、重叠、裁切、空白截图或浏览器错误。
