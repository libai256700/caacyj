# TC-ANSWERCORRECT-001 正确结果态与回归

## 1. 测试层级

`交互级`（接口响应使用 Playwright route 确定性夹具；不写入应用源码）

## 2. 对应验收项

- 验收项 ID：`AC-ANSWERCORRECT-001`、`AC-ANSWERCORRECT-101`
- 正式验收入口：`../../01-验收执行详情/AC-ANSWERCORRECT-001.md`、`../../01-验收执行详情/AC-ANSWERCORRECT-101.md`

## 3. 前置条件

- 环境前置：H5 测试服务可从 `http://127.0.0.1:5173/yunjikeji/` 访问；Google Chrome 与项目 Playwright 依赖可用。
- 账号前置：脚本仅在浏览器上下文写入确定性登录存储，不依赖真实账号。
- 数据前置：脚本拦截真实页面发出的练习 GET / POST 请求，并按场景返回结构与正式 service 契约一致的响应。

## 5. 执行动作

| 步骤 | 动作 | 预期结果 |
| --- | --- | --- |
| 1 | 在普通单选题选择正确答案 | 当前题显示“回答正确”、正确答案、试题详解和 AI 入口；提交后 GET 次数及题号不变 |
| 2 | 点击 AI 深度解答，再点击“下一题” | AI 入口使用真实页面导航；只有点击“下一题”后才 GET 下一题 |
| 3 | 正确提交多选题和文本题 | 两类题均保留完整正确结果态，不自动加载下一题 |
| 4 | 在末题正确提交，再点击“完成练习” | 提交后先显示解析且不跳转；点击完成后才 `reLaunch('/pages/home')` |
| 5 | 提交错误多选题并点击“下一题” | 既有错误结果态、正确/错误选项、解析、AI 入口及下一题承接不回归 |
| 6 | 快速重复触发单选提交 | POST 答案请求只有一次 |
| 7 | 在三种移动视口保留正确结果态 | 无横向溢出，底部操作区不越界、不遮挡答题卡滚动区 |

## 6. 期望结果

- 正确单选、多选、文本题均显示真实结果数据驱动的正确结果态。
- 普通题和末题均由显式按钮承接下一步；错误态、题型行为和防重复提交保持成立。
- 页面无未处理异常、控制台错误或失败网络请求。

## 7. 脚本入口

- 自动化脚本：`dev060-correct-result.spec.cjs`
- 依赖命令：`node dev060-correct-result.spec.cjs`
- 结果输出位置：当前目录 `playwright-results.json` 与 `correct-result-*.png`

## 8. 失败判定

- 正确提交后结果区不可见、题目 GET 次数增加或发生提前跳转。
- 显式下一题 / 完成动作、错误态、题型提交、防重复提交或移动端布局任一断言失败。
- 浏览器存在 page error、console error 或 request failure。
