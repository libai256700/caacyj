## 状态色

| 状态 | 色值 | 移动端使用场景 |
| --- | --- | --- |
| 正确 | `#2F9E73` | 答对反馈、正确选项、已掌握标签 |
| 错误 | `#D94B4B` | 答错反馈、错误选项、错题标记 |
| 警示 | `#F2A43A` | 倒计时临近结束、未完成、重点复习 |
| 信息 | `#168FC4` | 当前进度、系统提示、普通强调 |
| 禁用 | `#C7D1D6` | 不可点击按钮、未解锁模块 |

状态色不能只靠颜色表达。正确、错误、警示至少同时搭配图标、文字或边框变化，保证户外光线、低亮度屏幕和色弱用户也能识别。

## 移动端色调规则

1. 页面以浅背景为主，避免大面积高饱和蓝色铺底；蓝色只用于当前状态、关键行动和导航焦点。
2. 参考图的橙青渐变可用于首页学习进度卡、智能考试入口卡的局部装饰，不用于题干阅读区。
3. 紫光渐变只用于“智能推荐、模拟考试、能力分析”等智能化入口，数量要少，避免变成营销视觉。
4. 灰绿色用于完成、通过、稳定掌握等正向状态，不与错误红混用。
5. 题干、选项、解析优先保证阅读，不使用渐变文字，不放在复杂渐变背景上。
6. 移动端首屏应直接出现刷题、题库、模拟考试、错题本等核心入口，不做大幅品牌宣传首屏。
7. 深色模式或夜间环境下，建议将页面背景降为 `#101820`，卡片背景降为 `#17242C`，主文字改为 `#EAF3F6`，主色仍使用航空蓝，但降低渐变和阴影依赖。

## 移动端页面应用建议

### 首页 / 题库入口

- 首页以白底或极浅蓝底为主，顶部展示学习状态和继续刷题入口。
- “继续练习”使用航空蓝主按钮，建议固定在首屏核心位置。
- 题库入口按刷题类型分组：顺序练习用蓝色，错题本用暖橙，模拟考试或智能组卷用紫光。
- 学习进度卡可使用浅蓝底，进度条用航空蓝；连续练习、待复习数量可用少量暖橙强调。

### 刷题页

- 页面背景使用 `#F7FCFD`，题目主体使用白色题卡，减少视觉噪声。
- 顶部显示返回、题号、收藏或更多操作；题号和进度使用航空蓝。
- 题干区保持白底深色文字，字号和行距优先满足单手阅读。
- 选项按钮默认白底加浅边线；选中后使用浅蓝底加主色边线。
- 答题后正确项使用绿色，错误项使用红色，同时加图标或“正确 / 错误”文字。
- 底部操作区承载“上一题、下一题、提交、查看解析”等高频动作，背景用白色并加顶部细分割线。

### 答案解析页

- 解析区保持白底或浅蓝底块，避免大面积红绿背景。
- 正确答案用绿色小标签，用户答案错误时用红色小标签，标签不应遮挡题干。
- 易错提醒可使用浅橙底块，强调“为什么错”和“下次注意点”。
- “再练一题、加入错题本、查看同类题”放在底部操作区或解析后固定按钮区，主行动用航空蓝。

### 错题本

- 列表使用白色题卡，错题标记用红色小标签，不整卡变红。
- 筛选栏保持浅色，当前筛选项使用蓝色文字或浅蓝底。
- 已订正、已掌握使用灰绿色；待复习使用暖橙。
- 批量操作不应抢占主刷题路径，移动端可放入顶部更多菜单或底部浮层。

### 考试模拟

- 模拟考试入口可使用紫光辅助色，表达智能组卷和考试感。
- 考试中倒计时默认使用主文字，临近结束转为警示橙；只有超时或提交失败才使用红色。
- 答题卡浮层中，已答用航空蓝，未答用浅灰，错误回顾用红色，正确回顾用绿色。
- 交卷确认弹窗必须清晰显示未答题数量，主按钮使用航空蓝，危险操作不用大面积红底。

### 学习进度 / 成绩页

- 总体得分和掌握度使用航空蓝，薄弱项使用暖橙，已达标项使用灰绿色。
- 图表背景保持白色，网格线使用 `#DDECEF`，不使用深色仪表盘风格。
- 智能推荐卡可少量使用紫光渐变，但卡内正文必须落在纯白或浅色区域。
- 成绩页底部建议提供“继续刷题 / 复习错题 / 再次模拟”三类行动，主行动只保留一个蓝色按钮。

## 移动端组件建议

| 组件 | 建议 |
| --- | --- |
| 底部 Tab | 高度建议 56-64px；选中图标和文字使用 `#168FC4`，未选中使用 `#9DAAB2`；不要使用多色 Tab |
| 顶部导航 | 高度建议 44-48px；白底或浅蓝底；标题用主文字，返回和关键操作用主色 |
| 题卡 | 白底、`12px` 圆角、左右边距 12-16px；优先使用浅边线，轻阴影仅作层级辅助 |
| 选项按钮 | 最小高度 48px；上下间距 10-12px；圆角 8px；文本多行时保持左对齐和足够行距 |
| 答题状态 | 正确、错误、警示同时使用颜色、图标、文字；避免只靠红绿区分 |
| 进度条 | 高度 4-6px；底轨 `#DDECEF`，进度 `#168FC4`；不要使用过粗进度条压缩题目空间 |
| 浮层 / 弹窗 | 底部浮层优先；白底、圆角 12-16px；标题和正文保持高对比；遮罩不要过深 |
| 底部操作区 | 高度建议 64-76px；白底加顶部分割线；主按钮高度不低于 44px，固定在拇指易触区域 |
| 标签 | 使用浅底深字；错题、重点、已掌握分别使用浅红、浅橙、浅绿；标签高度建议 24-28px |
| 列表筛选 | 横向滑动 Chip 可用浅蓝选中态；单个 Chip 高度不低于 32px |

## 触控与可读性要求

1. 主按钮、底部操作按钮和选项按钮的触控高度不低于 44px，推荐 48px 以上。
2. 选项之间保留 10-12px 间距，避免单手刷题时误触。
3. 底部固定操作区不得遮挡最后一项选项或解析正文，页面底部需预留安全距离。
4. 题干和解析正文颜色优先使用 `#1F2F3A`，正文不使用低对比浅灰。
5. 浅色背景下红、绿、橙状态色要配合图标或文字；夜间环境下状态色要提高文字对比，不单靠背景色。
6. 渐变只用于入口卡、进度卡、智能推荐卡的局部背景，不用于高频阅读区。
7. 小程序和 H5 需考虑系统状态栏、浏览器底栏、安全区，底部 Tab 和底部操作区要避开手势区域。

## 禁用方向

1. 不使用参考图中的手机品牌、产品轮廓、品牌文字作为项目资产。
2. 不把移动端首页做成商品宣传页；首屏应直接服务刷题、考试、错题、解析和学习进度。
3. 不使用大面积深蓝、纯黑或高饱和霓虹渐变，避免偏离飞行学院学习平台气质。
4. 不使用桌面管理后台式的大表格、大侧栏、多列密集布局。
5. 不使用假徽章、假认证、假品牌图形制造“航空感”；航空感通过清爽蓝、秩序感、信息层级和低干扰刷题体验实现。
