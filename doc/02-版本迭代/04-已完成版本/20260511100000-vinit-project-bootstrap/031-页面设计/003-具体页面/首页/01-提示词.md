【当前页面设计与功能交互】
页面名称：
首页

页面目标：
作为进入应用后的第一屏总入口，清晰承接课程、题库、岗位信息和训练服务四个板块，让用户一眼看懂平台能学什么、练什么、看什么、去哪里继续下一步。

核心模块：

1. 课程板块：展示课程分类、课程内容、推荐课程、继续学习入口和课程进度提示。
2. 题库板块：展示题库练习、模拟考试、错题复习和题库入口。
3. 岗位信息板块：展示招聘信息、岗位信息、岗位分类和岗位入口。
4. 训练服务板块：统一使用“训练服务”命名，展示模拟飞行训练、实操训练、专项训练提升、训练预约或服务介绍等入口，不再使用“增值服务”旧说法。

关键交互：

1. 点击课程板块进入课程列表或课程详情。
2. 点击题库板块进入题库练习、模拟考试或错题复习入口。
3. 点击岗位信息板块进入招聘和岗位信息列表。
4. 点击训练服务板块进入训练服务相关页面或服务介绍。
5. 四个板块都应具备明确可点击的首页入口感，但仍保持首页信息层级，不做成纯列表页或纯卡片堆叠页。

关键状态：

1. 首屏默认态：四个板块均可见，课程板块作为最强主入口。
2. 内容丰富态：课程、题库、岗位信息和训练服务均支持推荐卡片或摘要展示。
3. 内容较少态：保留板块标题、轻量占位和引导按钮，不破坏整体框架。
4. 滚动浏览态：顶部与板块层级保持清晰，用户下滑后仍能快速识别四大入口。
