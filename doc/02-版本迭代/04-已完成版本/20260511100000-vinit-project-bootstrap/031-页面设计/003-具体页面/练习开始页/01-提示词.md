【当前页面设计与功能交互】

页面名称：练习开始页

页面目标：
作为用户进入练习前的确认页，集中展示本次练习的关键信息，让用户在开始前快速确认练习范围和规则。画面只围绕“练习信息概览”和“底部操作按钮”展开，不扩展成答题过程、成绩分析、学习报告或其他业务模块。

核心模块：

1. 练习信息概览模块：以信息卡或上下分区卡片展示科目、题目的分类、题目的编号、题量、总分、答题时间、阅卷方式等信息，其中科目、题目的分类和题目的编号要更醒目，便于开始前快速识别。
2. 底部操作模块：只保留“开始练习”和“错题复练”两个操作按钮，形成清晰主次关系，不增加第三个操作，不增加复杂跳转说明或额外工具区。
3. 还需要有返回上一页的图标

关键状态：

1. 默认状态：练习信息完整展示，主视线先看到科目与题目分类，底部“开始练习”为主按钮，“错题复练”为次按钮。
2. 信息较长状态：科目、分类或题号较长时，仍保持标题和信息行清晰可读，不挤乱整体秩序。
3. 规则固定状态：阅卷方式始终展示为“系统阅卷”，作为稳定规则信息存在，不画成可切换控件。
4. 行为克制状态：页面保持前置确认页属性，不出现答题过程、成绩分析、学习报告、题目列表或其他额外模块。

展示要求：

1. 画面重点放在练习前的信息展示和版式关系，不要做成正式答题页。
2. 页面必须完整表达科目、题目的分类、题目的编号、题量、总分、答题时间、阅卷方式（固定为系统阅卷），以及“开始练习”“错题复练”两个按钮。
3. 整体保持简洁、专业、可读，继续沿用飞行学院无人机教学培训平台的统一视觉气质。
4. 不要虚构额外模块，不要加入复杂交互说明，不要扩展第三个业务入口。
