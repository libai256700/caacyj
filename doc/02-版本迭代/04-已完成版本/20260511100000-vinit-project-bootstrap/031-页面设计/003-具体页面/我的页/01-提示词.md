【当前页面设计与功能交互】
页面名称：
我的页

页面目标：
作为个人中枢页，集中展示昵称、学号、学校/专业、课程与练习概览、简历状态、投递中的职位数、面试进展和常用快捷入口，让用户一眼看清自己的学习进度、求职进展和个人资料状态。

核心模块：
1. 个人信息模块：展示昵称、学号、学校、专业和头像/身份区。
2. 学习概览模块：展示课程数量、练习数量、学习进度和阶段性完成情况。
3. 简历状态模块：展示简历是否完善、是否已投递、是否待优化等状态。
4. 求职进展模块：展示投递中的职位数、面试进展和近期动态。
5. 快捷入口模块：提供课程、练习、简历、投递记录、面试安排和设置等入口。

关键交互：
1. 点击个人信息区域进入资料编辑或账户信息页。
2. 点击课程与练习概览查看学习详情。
3. 点击简历状态查看简历完善或更新入口。
4. 点击投递中的职位数或面试进展进入求职进展页。
5. 点击快捷入口直达课程、练习、简历、投递记录和设置。

关键状态：
1. 默认状态：个人资料、学习数据和求职数据齐全，突出身份感和中枢感。
2. 求职活跃状态：投递和面试数据更明显，强调进展提醒。
3. 学习活跃状态：课程与练习概览更突出，强调学习任务继续入口。
4. 数据较少状态：保留个人信息和快捷入口，避免信息区过空。
5. 空状态：未完善资料或未开始求职时，给出补全资料和开始练习的引导。
