# TA-VAPP-DB-001 数据库脚本与测试库验证

## 验收类型

`接口级验收`

## 业务场景

六页面联调需要测试库承接用户、练习、AI 解答和我的页聚合相关数据，数据库变更必须通过正式脚本和正式连接记录执行。

## 验收标准说明

数据库建表、初始化、校验和回滚必须有正式脚本入口；测试库连接必须登记在正式应用连接记录中，不能只停留在代码配置或口头说明。

## 核心对象

- `yunjikeji` 测试库正式连接记录
- 建表脚本
- 初始化脚本
- 校验脚本
- 回滚脚本
- 数据库执行记录

## 前置条件

1. `applications.md` 已补齐 `yunjikeji` 测试库库名、主机端口、账号口径、连接命令和权限边界。
2. 数据库脚本已按版本目录归档。
3. 执行前备份、执行审批和回滚口径已明确。
4. 生产数据库不得被直接操作；生产环境只允许只读查询。

## 触发动作

1. 按正式连接记录连接测试库。
2. 在测试环境执行或复验建表、初始化和校验脚本。
3. 通过只读查询核对关键表、字段、索引和初始化数据。
4. 必要时按正式回滚入口验证回滚可行性。

## 期望结果

1. 测试库连接入口可复用、可审计。
2. 建表和初始化脚本幂等或具备明确重跑边界。
3. 关键表结构、索引、字段注释和初始化数据符合当前版本设计。
4. 校验结果能支撑 `BA-VAPP-DATA-001` 的数据结果业务验收。
