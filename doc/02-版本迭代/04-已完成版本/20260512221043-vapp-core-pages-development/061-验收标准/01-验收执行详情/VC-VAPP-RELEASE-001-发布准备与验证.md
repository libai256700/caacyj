# VC-VAPP-RELEASE-001 发布准备与验证

## 验收类型

`闭环项`

## 业务场景

测试环境全部正式验收通过后，版本仍需等待用户明确发布允许，并完成生产发布和发布验证。

## 验收标准说明

发布不得在测试环境验收未通过、用户未明确允许或缺陷未清零时提前执行；生产发布前必须具备备份、回滚和发布验证口径。

## 核心对象

- 用户发布允许
- 发布标签
- 生产部署入口
- 备份记录
- 回滚方案
- 发布验证记录

## 前置条件

1. 测试环境全部业务验收和技术验收已通过。
2. `VC-VAPP-DEFECT-001` 已完成。
3. 用户已明确允许发布。
4. 生产部署入口、备份和回滚方案已确认。

## 触发动作

1. 获取用户明确发布允许。
2. 创建或确认发布标签。
3. 按发布规范执行生产发布。
4. 执行生产发布验证。

## 期望结果

1. 发布动作有明确批准来源。
2. 发布前已备份，且回滚路径可执行。
3. 生产验证结果可复验。
4. 未满足前置条件时，版本不得进入发布执行。
