# VC-VAPP-DEFECT-001 缺陷清零闭环

## 验收类型

`闭环项`

## 业务场景

正式联调和测试环境验收过程中暴露的问题必须完成记录、修复、重跑和结论回写，不能只在聊天中说明已处理。

## 验收标准说明

所有影响六页面主链路、后端接口、数据库脚本、测试环境部署和发布判断的问题，都必须有明确状态和复验入口；未关闭阻塞问题存在时不得推进版本通过。

## 核心对象

- 联调问题记录
- 正式验收未通过项
- 修复记录
- 重跑复验记录
- `02-验收结论.md`

## 前置条件

1. `TASK-018` 或 `TASK-012` 已产生正式执行记录。
2. 未通过场景已定位到对应验收项。
3. 修复责任和复跑入口已明确。

## 触发动作

1. 汇总未通过项和阻塞项。
2. 对每个问题记录影响范围、修复入口和重跑入口。
3. 修复后只重跑目标场景及必要关联场景。
4. 将最新结论回写到 `02-验收结论.md`。

## 期望结果

1. 无未关闭阻塞缺陷。
2. 已关闭问题都有复跑证据。
3. 未通过项不会被删除或绕过，而是通过修复和重跑改变状态。
