# BA-VAPP-DATA-001 关键业务数据承接

## 验收类型

`数据结果业务验收`

## 业务场景

用户完成登录、进入首页、开始练习、查看 AI 深度解答和查看我的页后，相关业务结果应能被测试库、接口返回或正式结果载体正确承接。

## 验收标准说明

关键业务数据必须有可核对入口，能证明页面展示和后端数据结果一致；不得只凭页面静态展示判定数据链路成立。

## 核心对象

- 登录用户身份结果
- 首页聚合结果
- 练习过程结果
- AI 深度解答结果
- 我的页用户聚合结果
- `yunjikeji` 测试库正式连接记录
- 数据库脚本与初始化数据

## 前置条件

1. `C:\Users\13174\.devcenter\Operations\ApplicationConnections\Test\applications.md` 已补齐 `yunjikeji` 测试库正式连接记录。
2. 建表脚本、初始化脚本和回滚脚本已有正式入口。
3. 数据变更边界、只读查询边界和执行审批口径已明确。
4. 页面联调使用的测试账号与数据样本已确认。

## 触发动作

1. 使用测试账号完成六页面主链路操作。
2. 通过正式接口返回、测试库只读查询或脚本执行结果核对关键业务数据。
3. 对照页面展示核对用户身份、练习状态、AI 解答结果和我的页聚合结果。

## 期望结果

1. 页面展示结果与接口返回、测试库或正式结果载体一致。
2. 初始化数据和用户操作数据可区分，不混用历史脏数据。
3. 数据库脚本执行结果可复验，失败时有明确回滚或重跑入口。
4. 没有测试库正式连接记录前，本项不得判定通过。
