# 实施记录

## 1. 基本信息

- 任务名称：章节测试提交与重复测试问题修复
- 实施日期：2026-08-21

## 2. 根因

- 章节测试已答完后，历史批次可能仍保留 `is_completed = 0`，再次进入时会被当成“未完成批次”恢复。
- 该批次实际已无待答题目，后端继续计算下一道未答题时触发“未完成练习批次没有待答题目”，表现为答完不能提交或测过一次后不能再测。

## 3. 修复内容

- 章节测试读取最新批次详情时，若批次已全部作答但完成态仍为 false，则自动补正为 `completed=true`。
- 章节测试恢复未完成批次前，先做同样的完成态补正；已全部作答的脏批次返回 `null`，让下一次开启继续走原有新建批次逻辑。
- 补正逻辑仅限章节测试；真实未完成的章节测试不补完成态，继续沿用原恢复逻辑，返回原批次并定位到第一个未答题。
- 补充契约测试，覆盖正常答完置完成态、脏完成态自动修正后可重新开始章节测试、以及未完成章节测试恢复到未答题。
