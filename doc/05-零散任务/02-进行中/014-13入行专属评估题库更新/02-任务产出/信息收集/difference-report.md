# 来源与现有数据差异报告

- 比对时间：`2026-08-18T12:34:35+08:00`
- 来源：`https://caacyj.com/` 当前公开 V3 页面。
- 现库：当前运行程序实际连接的 `yunjikeji`，目标分类主键固定为 `13`。
- 标准答案规则：用户确认全部为空是正确现状；本报告不把 `is_correct = 0` 列为缺失，不尝试补值。

## 结论

需要更新。来源 V3 与现库 21 道旧版平铺问卷不是同一题目结构，无法通过少量文本修订对齐。
来源定义 `41` 个顶层题目（另含 A3 的 8 个矩阵子项）；现库 `21` 题、`101` 个选项、`0` 个子项。题干完全一致 `0` 题；来源缺入现库 `41` 题；现库无来源同名题 `21` 题。

关键结构差异：

- 来源为 6 步动态问卷，报告目标最多选 3 项并决定 A-E 模块是否出现；现库为 4 个 step 的固定 21 题。
- 来源核心量表含 Q6-Q15 五维 Likert 题，现库没有同题干。
- 来源 A3 是 8 行 × 3 级接受度矩阵；现库子答案表为空，三表映射方式尚未由真实接口契约确认，不能在信息收集阶段自行决定拆题或子项表达。
- 现库有 3 道题 `question_status = 0`，来源公开页面没有对应停用题。
- 来源前端只公开提交与轮询入口，不公开评分/报告结果映射；但这不影响本轮标准答案空值规则。
