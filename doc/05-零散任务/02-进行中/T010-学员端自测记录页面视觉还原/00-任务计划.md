## 2. 任务目标

1. 将学员端自测记录页严格还原为已批准的 V015 移动端视觉稿。
2. 页面展示最近一次真实自测的完成时间、前三项回答快照、评分、答题数和结论，不写死年龄区间、日期、题数或答案。
3. 修正现有详情链路中真实完成时间未返回、选项 ID 与答案文案重复展示及未评分问卷被误算为满分的问题。

## 3. 任务范围

- 包含：自测记录正式页面、前端自测记录适配逻辑、记录详情的最小完成时间字段扩展、必要后端测试、移动端视觉与交互回归。
- 不包含：自测题库内容调整、问卷评分规则重设计、数据库表结构变更、AI 报告正文改造、登录流程或其他练习页面重构。

## 4. 统一原则

- 先读任务详情：阶段任务总表只做导航；真正实施前，必须先阅读对应任务详情。
- 计划启动门禁：`01-验收标准.md` 未收口前，实施任务不得进入 `进行中`。
- 正式验收承载位置：正式验收标准统一写到 `01-验收标准.md`，本文只保留验收入口和状态门禁。
- 现有改动保护：承接工作区中 `self-test-record.vue` 及相关视觉资产的已有改动，不覆盖、不回退其他任务成果。
- 数据真实性：页面不得出现固定日期、固定年龄、固定题数或固定答案；完成时间优先使用服务端自测结果时间，回答内容使用对应记录详情。
- 单一实现：只修改现有正式页面及既有数据服务，不新建同义页面或演示组件。
- 人工审核门禁：只有“独立验收通过 + 用户明确审核通过”同时满足后，才允许归档。
