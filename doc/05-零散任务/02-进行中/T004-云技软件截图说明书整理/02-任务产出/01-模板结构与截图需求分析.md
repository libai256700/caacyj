## 4. 截图版式规则

1. 每个功能组先写编号标题，再写一段或多段功能说明，最后放对应界面截图。
2. `3.1 开屏引导`、`3.2 用户注册`、`3.3 用户登录` 使用单列表格，一行一图；表格网格宽约 15.03 cm，Table Grid 边框约 0.5 pt。
3. `3.4` 至 `3.7` 使用无图注的图片段落。绝大多数段落一图，但 `3.4.2` 有一个段落包含两次图片引用。
4. 主要截图显示宽度约 14.63 cm；常见显示尺寸为 14.63 cm x 10.97 cm。除注册首图外，显示纵横比与源图纵横比误差不超过约 0.08%。
5. 注册首图 `image7.png` 原图为 2048 x 1536，显示为约 14.50 cm x 5.80 cm；XML 显式裁掉右侧约 0.856% 和底部约 47.179%，裁切后的纵横比与显示尺寸匹配，不属于拉伸变形。
6. 文档没有显式分页规则，也没有“每页一图”的结构；应让内容自然分页，不得自行添加固定分页要求。
7. 图片段落没有独立图号或图注。页面名称由前置功能标题承担。

主要风险及处置：

1. **原独立模板缺失**：当前只能证明候选第 3 章结构可用，不能声称与原 `来绘软件截图.docx` 完全一致。
2. **旧水印和品牌**：页眉水印、来绘标识、旧头像及所有旧业务文字必须清除。
3. **敏感信息**：候选注册截图含手机号；新截图只能使用明确的测试数据并在交付前复核。
4. **加载态**：候选存在加载骨架画面；新截图必须无持续加载遮罩、白屏或关键资源失败。
5. **重复媒体**：候选 `image21.png` 被引用两次；新清单必须按页面语义采集，不能用无说明的重复图补数量。
