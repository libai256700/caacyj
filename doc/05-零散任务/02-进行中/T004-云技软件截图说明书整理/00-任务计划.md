## 2. 任务目标

1. 核实用户提供的截图模板来源与排版结构，按旧项目截图文档的组织方式整理当前飞行学院（云技）项目界面。

3. 在用户桌面生成可正常打开、可继续编辑的 `云技软件截图.docx`，且不覆盖已经交付的两份源码说明书。

## 3. 任务范围

- 包含：识别 `~$来绘软件截图.docx` 锁文件并查找可用模板；核对 `来绘_软件设计说明书.docx` 是否包含对应截图版式；记录最新代码与工作区指纹；启动当前客户端或管理端；使用 Playwright 采集真实页面截图；按模板生成并校验 Word。
- 不包含：复用项目历史截图冒充本次采集；修改业务源码来适配截图；部署生产环境；执行数据库写操作；覆盖 `云技_软件设计说明书源代码.docx` 或 `云技_软件设计说明书源代码_1.docx`；未经用户确认提前归档。

## 4. 统一原则

- 先读任务详情：真正实施前必须先阅读对应任务详情。
- 模板真实性：`~$来绘软件截图.docx` 仅作为锁文件线索，不作为正文模板；必须找到可解析的真实 DOCX 或从 `来绘_软件设计说明书.docx` 中确认可复用截图版式。
- 最新代码门禁：截图前记录当前 Git HEAD、`git status`、项目路径、启动命令和启动时间；截图必须来自该次启动的页面。
- 浏览器证据：页面截图统一使用 Playwright；每张图记录路由、页面名称、视口、截图时间和源图片路径。
- 截图真实性：禁止直接从旧 Word、项目历史文档、`tmp` 或旧测试截图目录复制图片作为本次界面截图。
- 正式验收承载位置：标准在 `01-验收标准.md`，模板分析、截图清单、图片、生成记录和验收结论统一在 `02-任务产出/`。
- 未通过场景门禁：只要正式验收项仍有 `未通过`，不得进入人工审核。
- 人工审核门禁：只有“独立验收通过 + 用户明确审核通过”同时满足后，才允许归档。
