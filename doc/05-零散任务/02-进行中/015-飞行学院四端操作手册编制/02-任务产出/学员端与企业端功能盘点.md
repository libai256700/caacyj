> 盘点日期：2026-08-31  
> 结论口径：以当前工作区代码、路由、接口配置、本地监听状态和已有页面截图资产为依据；未使用账号凭据，不把未实际登录验证的能力写成已验证结果。

## 1. 结论摘要

1. 学员端和企业端不是两个独立工程，而是共用 `code/develop/yunjikeji` 这一套 Vue 3 + uni-app 工程，通过 `loginIdentity = student | enterprise` 区分身份和首页。
2. APP 对外名称为“小技”，当前版本 `1.0.3`；默认启动页是 `/pages/home`，未登录会被守卫送到 `/pages/auth/login`。
3. 学员端当前可见底部导航为“首页 / AI助手 / 我的”；企业端复用同一底栏，但实际落点为“学员管理 / 客服 / 我的”。
4. 学员端主要闭环包括：短信或本机号码登录、组织申请与企业审核、逐题练习、章节测试、三类考试、错题复练、自我测评、职业规划评测、报告查看、岗位筛选与外部详情、AI 助手、客服会话、资料与账号操作。
5. 企业端主要闭环包括：企业身份登录、待审核学员查询及同意/拒绝、已审核学员会话列表、与学员发送文字/图片/视频、企业资料展示、客服/协议/关于/注销/退出。
6. `企业注册`和`审核进度`两个页面已在 `pages.json` 注册，接口也已实现，但当前代码没有从登录页、企业首页或“我的”页进入它们的入站导航。正式手册只能将其标为“直达路由/待补正式入口”，不能写成“企业首次登录自动进入注册审核”。
7. `设置`、`绑定手机号`、`自测记录`同样存在已注册页面或处理函数，但当前“我的”页没有可见入口：账号安全菜单被注释，设置按钮未渲染，自测记录数组第二项未渲染。它们不应作为当前主导航能力描述。
8. 本地 H5 已在 `http://127.0.0.1:5173/` 监听，本地后端在 `http://127.0.0.1:48080/` 监听；未带令牌访问组织和题库接口均返回业务码 `401`、提示“账号未登录”，说明核心页面验证必须使用有效测试账号。
9. Chrome DevTools MCP 能力在当前会话可见，但当前 Chrome 没有 DevTools 调试端口，调用返回 `Could not find DevToolsActivePort`，因此本轮未能采集新的运行时截图。仓库已有 2026-08-14 的两端页面截图，可做页面识别参考，正式手册仍应在 TASK-004 使用当前运行页面重新截图。

### 2.3 APP 与 H5 能力差异

- “本机号码一键登录”只在 `APP-PLUS` 编译分支执行，依赖 UniVerify、SIM 卡、运营商网络、uniCloud 函数 `yj-univerify-login` 和后端共享配置；H5 应使用短信验证码登录。
- 拍照上传营业执照、上传头像、发送图片/视频在 APP 与 H5 的文件处理方式不同，正式截图需分别注明运行平台。
- 岗位详情在 APP 使用 `plus.runtime.openURL`，H5 使用 `window.open`；两者都不在 APP 内展示岗位详情页。
- Android 申请了网络、相机、存储、设备状态等权限，首次使用拍照或媒体能力时可能出现系统授权弹窗。

## 3. 共用登录、身份和导航机制

### 3.1 启动与登录守卫

| 场景 | 当前行为 | 证据 |
| --- | --- | --- |
| 未登录打开首页/业务页 | 保存当前业务页后重新加载登录页 | `src/stores/appState.ts:349-380` |
| 打开 `/pages/index` | 无会话转登录，有会话转首页 | `src/pages/index.vue:12-28` |
| 学员身份登录后 | 进入 `/pages/home` | `src/pages/auth/login.vue:713-730` |
| 企业身份登录后 | 先进入 `/pages/home`，随后首页守卫转 `/pages/enterprise/students` | `src/pages/home.vue:458-470` |
| 会话过期 | 接口统一清理会话并转登录页 | `src/services/request.ts`、各服务 `handleUnauthorizedResponse` |

### 3.2 登录页可见操作

1. 在页首身份切换中选择“学员登录”或“企业登录”。
2. 选择“其他手机号码登录”（实际为本机号码一键登录）或“短信验证码登录”。
3. 短信登录时输入 11 位手机号，点击“获取验证码”；倒计时为 60 秒。
4. 输入 6 位验证码。
5. 勾选“我已阅读并同意”，可分别打开《用户服务协议》和《隐私政策》。
6. 点击“登录 / 注册”。学员调用 `/app-api/yj/customer-auth/login-or-register`，企业调用 `/app-api/yj/company-auth/login-or-register`。
7. 成功后刷新令牌、取得当前用户资料并进入对应首页。

登录前置和异常：

- 未勾选协议会提示“请先同意用户协议和隐私协议”。
- 手机号格式不正确、验证码为空或不是 6 位均会在本地阻止提交。
- 一键登录不支持 H5；APP 还可能因运营商网络、UniVerify 模块、uniCloud 额度或配置不一致失败，页面会引导改用短信登录。
- 当前实现的按钮文案是“登录 / 注册”，即手机号验证码链路同时承接登录或注册。

### 4.2 学员首页

学员首页实际由一张当前首页参考图和覆盖其上的可点击热点组成，热点功能均连接真实处理函数。可见入口为：

- 开始测评：打开“自我评测 / 职业规划评测”选择弹层。
- 评测结果：打开“自我评测报告 / 职业规划评测报告”选择弹层。
- 逐题练习。
- 章节测试。
- 模拟考试。
- 错题练习，同时显示错题总数。
- 岗位信息。
- 联系客服。
- 底部“首页 / AI助手 / 我的”。

进入首页时会同步错题数和学员组织审核状态。预览会话会把组织视为已通过，但正式账号不得用预览状态冒充真实审核结果。

### 4.3 组织申请与能力解锁

#### 4.3.1 申请步骤

1. 从“我的 > 绑定组织”进入；也可能在访问受限题库、考试或岗位详情时由弹窗引导进入。
2. 在“选择所属组织”页输入企业名称关键词。
3. 页面只列出接口 `/app-api/yj/tenants?limit=100` 返回的组织；代码把这些组织统一标为“企业组织”，申请模式为“申请加入”。
4. 点击“申请加入”或驳回后的“重新申请”。
5. 在确认弹层填写真实姓名、身份证号、性别；页面先保存学员资料，再提交加入审核。
6. 成功后提示“申请已提交”，状态变为待审核。
7. 企业管理员在企业端同意后，学员状态变为已绑定；拒绝后页面显示驳回原因并允许重新申请。
8. 学员也可以点击“暂不绑定组织”继续使用不受限能力，之后从“我的”重新申请。

#### 4.3.2 状态和影响

| 状态 | 页面表现 | 能力影响 |
| --- | --- | --- |
| 未绑定 | 可选择组织并申请，也可跳过 | 题库主题 1 以外的主题、三类考试和岗位详情会要求绑定 |
| 待审核 | 显示已申请组织和等待审核提示 | 尚未解锁受限能力 |
| 已通过 | 显示当前组织/已绑定 | 可进入受限题库、考试和岗位详情 |
| 已拒绝 | 显示驳回原因，可重新申请 | 尚未解锁受限能力 |
| 已跳过 | 可继续使用小技，后续重新绑定 | 同未绑定限制 |

代码层的特殊规则：题目主题 ID 为 `1` 时不要求组织绑定，其他主题要求审核通过；三类考试全部要求审核通过；岗位列表可以查看，但“查看详情”要求审核通过。

### 4.4 逐题练习、章节测试和错题复练

#### 4.4.1 逐题练习

1. 首页点击“逐题练习”。
2. 系统加载启用中的题目主题。
3. 选择主题；受限主题会先检查组织审核状态。
4. 若存在未完成批次，会继续上次题目；否则创建练习批次并进入批次详情或答题页。
5. 批次详情展示题目分类、题量、总分、答题时间和考试类型。
6. 点击“开始练习”。
7. 单选题点击选项后自动判题；多选题/文本题需要点击“提交”。
8. 判题后查看“回答正确/回答错误”、正确答案、试题详解、答题摘要。
9. 点击“下一题”；最后一题显示“完成练习”或“完成测试”。
10. 完成后进入“答题详情”，可查看概述并返回首页。

#### 4.4.2 章节测试

流程与逐题练习相同，但创建的是章节测试批次；答题页不会展示逐题解析，完成后统一进入记录详情。

#### 4.4.3 错题复练

1. 首页“错题练习”显示错题总数；总数为 0 时不会启动。
2. 进入分类页后查看主题错题数。
3. 选择有错题的主题并创建错题复练会话。
4. 若当前主题没有错题，页面提示“当前暂无错题可练习”。

#### 4.4.4 AI 深度解答

答题结果存在解析时可点击“AI 深度解答”：

- 展示错题回顾、你的选择和正确答案。
- 首选流式 AI 解答；不支持时回退到普通接口/知识库查询。
- 支持继续追问。
- 需要有效练习会话和题目参数；服务失败时显示重新加载。

### 4.5 三类考试

1. 首页点击“模拟考试”。
2. 未绑定组织时出现组织绑定提示。
3. 已绑定后进入“选择考试模式”。界面依次显示“理论考试 / 综合考试 / 教员考试”。
4. 选择一种模式创建正式批次，进入批次详情。
5. 核对题量、总分、答题时间和考试类型后开始答题。
6. 答题页显示剩余时间；时间到会提示“考试时间已到，本次考试结束”，随后进入答题详情。

注意：当前代码中界面“理论考试”调用 `comprehensive-exam`，界面“综合考试”调用 `theory-exam`。该映射与名称直觉相反，必须在实际测试账号下核对后再写具体规则，不能自行对调或解释。

### 4.6 自我测评

1. 首页点击“开始测评 > 自我评测”。
2. 如果检测到报告正在初始化分析，页面提示稍后再试。
3. 如果已有完成记录，询问是否重新测评；确认后重置已完成测评。
4. 首次进入先显示“填写基本资料”：姓名和手机号必填；身份证号、毕业院校、专业为选填。
5. 点击“下一步”保存资料并加载题目。
6. 普通题逐题作答；“核心量表”和“补充模块”按组展示。
7. 可用“上一题/上一组”和“下一题/下一组”导航。
8. 最后一题点击“提交并生成报告”。
9. 提交后显示报告生成中的提示并返回首页。
10. 首页“评测结果 > 自我评测报告”进入报告页；若未完成会明确提示继续测评。
11. 报告处于 PENDING 时每 3 秒轮询；SUCCESS 显示富文本报告；FAILED 显示失败原因和“重新生成自测报告”。

### 4.7 职业规划评测

1. 首页点击“开始测评 > 职业规划评测”。
2. 已有记录时询问是否重新评测。
3. 逐题完成工作价值等题目；“兴趣倾向”按组填写。
4. 工作价值规则包括“最看重的工作价值只能选择 3 项”，最不看重项目不能与最看重 3 项重复。
5. 最后一题点击“提交并生成报告”。
6. 页面提示报告正在生成，回首页后从“评测结果 > 职业规划评测报告”查看。

### 4.8 练习记录和结果

“我的 > 练习记录”支持：

- 按练习分类筛选。
- 按全部、近 7 天、近 30 天等时间范围筛选（以页面实际选项为准）。
- 每条记录显示标题、满分、实际得分、正确数、错误数、练习时间。
- 当前记录卡组件没有点击进入详情的事件；答题详情主要在完成练习后自动进入。

`自测记录`页面虽可直达，能显示最近一次自测时间、前三条回答快照、报告状态/结论/下一步并进入报告，但当前“我的”页无可见入口，应标为限制。

### 4.9 岗位招聘

2. 列表默认每页 10 条，可下拉刷新、滚动加载更多。
3. 可按关键词、地域、工资区间筛选。

### 4.10 AI 助手

### 5.3 学员加入审核

#### 5.3.1 列表范围

- 页面标题语义为“小技企业学员管理”。
- 当前接口固定请求 `pageNo=1&pageSize=200&auditStatus=1`，因此主列表口径是“待审核加入申请”，不是完整历史学员档案。
- 页面支持按学员昵称或手机号筛选。
- 页面支持选择开始时间和结束时间，按申请时间筛选。
- 待审核排在最前，列表再按申请时间倒序；但接口刷新后通常只保留待审核数据。

#### 5.3.2 审核步骤

1. 从企业首页进入“加入申请”。
2. 必要时输入昵称/手机号，或设置申请开始、结束时间。
3. 找到状态“待审核”的学员。
4. 点击“同意”或“拒绝”。
5. 系统调用企业学员审核接口，审核值分别为 `2`（通过）和 `3`（拒绝）。
6. 成功后重新加载待审核列表，并提示“已审核”或“已拒绝”。
7. 通过后学员可解锁受限题库、考试和岗位详情；拒绝后学员组织页显示驳回状态。

当前页面没有二次确认弹窗、没有拒绝原因输入框，也没有学员详情页；手册不得增加这些步骤。

## 8. 不可验证项与风险

1. 未提供或未在正式记录中发现可用于本轮的学员、企业测试手机号、验证码或一键登录凭据，不能实际完成登录、组织审核、答题、报告生成和会话发送。

8. 设置、账号安全、绑定手机号、自测记录页面存在代码但没有当前可见入口；不可将直达路由等同于正常菜单功能。

10. 岗位详情是外部链接，手册应说明会离开 APP/打开新窗口；具体第三方页面不在本工程控制范围内。
11. 报告由后端异步生成；截图时必须区分 PENDING、SUCCESS、FAILED，不得用 URL 参数或本地缓存伪造“真实报告成功”。
