## 1. 采集原则

1. 仅做只读导航和页面快照，不提交答题、考试、测评、资料、组织申请、消息或企业审核。
2. 页面快照先检查手机号、验证码、姓名、证件、企业资料和会话内容，再决定是否保存。
3. 学员登录表单曾出现用户输入的完整手机号和验证码，该状态未截图、未落盘、未写入手册。
4. 企业学员审核、会话列表和“我的”含真实会话数据，截图前仅在浏览器 DOM 中替换为明确的脱敏文字；没有修改接口、服务端或业务数据。
5. 图片统一写入 `code/develop/操作手册/images/`，Markdown 使用 `images/...` 相对路径。

## 4. 未采集页面与原因

| 页面/状态 | 未采集原因 | 手册口径 |
| --- | --- | --- |
| 带用户输入的登录表单 | 出现完整手机号和短信验证码 | 不保存截图；登录步骤由无会话页和代码共同确认 |
| 学员组织申请表单与状态 | 含真实姓名、身份证号，提交会改变业务数据 | 代码确认、需账号/权限复验 |
| 答题、交卷、考试计时 | 创建批次或提交答案会写入业务数据 | 只读到主题/模式页，后续按代码说明 |
| 自我/职业测评与报告 | 可能含个人资料，提交和重新生成会写入数据 | 代码确认、需账号复验 |
| 学员/企业聊天详情 | 可能含真实会话，发送消息会写入数据 | 只展示脱敏企业会话列表 |
| 企业审核处理后状态 | 同意/拒绝会改变学员权限 | 只展示处理前页面，结果按接口和代码说明 |
| 企业注册/审核进度 | 当前无正式入站导航，资质和状态敏感 | 作为“直达页面/待确认流程”说明，不冒充正常入口 |
