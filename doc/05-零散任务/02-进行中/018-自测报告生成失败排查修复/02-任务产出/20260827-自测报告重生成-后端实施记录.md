# 自测报告重生成后端实施记录

## 实现范围

- 新增接口：`POST /app-api/yj/practices/assessment-result/{recordId}/regenerate`。
- 接口只接收练习 `recordId`，登录身份由 `AppMobileAuthUtils.requireStudentLoginUser()` 获取。
- 仅允许当前用户、已完成、`ASSESSMENT` 模式且关联 `yj_assessment_result.report_status=FAILED` 的记录重生成。
- 从练习记录、目录批次和持久化作答详情恢复 `practiceId`、租户、用户、题量、正确数和答案集合，不接收前端提交的完整生成参数。
- 使用条件更新将同一报告记录从 `FAILED` 原子认领为 `PENDING`，然后复用 `enqueueAssessmentEvaluation -> applyAssessmentEvaluation`；不新增替代报告记录。
- `SUCCESS` 和 `PENDING` 请求幂等返回，不重复入队；成功与失败终写均要求当前状态仍为 `PENDING`，避免迟到任务覆盖终态。

## 真实入口与日志

- 真实生成入口：`applyAssessmentEvaluation(AppPracticeAnswerSubmitRespVO response, PracticeRuntimeSession session, Long recordId, Long assessmentResultId, List<AppPracticeRecordAnswerRespVO> answers)`。
- 日志字段：`method=applyAssessmentEvaluation`、`response.totalQuestions`、`response.correctCount`、`session.agentTenantId`、`session.userId`、`session.practiceId`、`session.mode`、`session.recordId`、`recordId`、`assessmentResultId`、`answers.size`。
- 日志不输出题干、自由文本答案、Token、密码、手机号或证件号。
