# T0018 自测报告重生成前端实施记录

## 实施结果

- 自测报告 FAILED 页面新增“重新生成自测报告”按钮，其他状态不展示。
- 点击时复用页面已有 `recordId`，调用 `POST /app-api/yj/practices/assessment-result/{recordId}/regenerate`，请求无 body。
- 请求期间按钮进入 loading/disabled 状态，处理函数同时防止重复调用。
- 接口返回后清除失败提示；PENDING 状态复用原 3 秒轮询，SUCCESS 状态立即加载真实报告。
- 请求失败时保留 FAILED 状态，恢复按钮，并通过页面提示和 toast 展示错误信息。
- 返回首页入口保留；FAILED 状态下调整为次要按钮。
