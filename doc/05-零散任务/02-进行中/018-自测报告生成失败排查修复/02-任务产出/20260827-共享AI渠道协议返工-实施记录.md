- 验证：`DeepSeekOpenAiClientTest` 5/5、Maven compile 通过；相关生产/测试文件没有本地伪 HTTP 服务或替身代码。
- 保留：真实外部 AI HTTP 和完整业务调用链需在正式测试环境使用真实配置联调，不得以本地替身代替。
