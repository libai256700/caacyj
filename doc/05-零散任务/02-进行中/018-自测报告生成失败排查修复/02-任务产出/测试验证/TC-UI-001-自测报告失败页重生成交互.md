`交互级`

## 2. 对应验收项

- 验收项 ID：`BA-T0018-INT-001`、`BA-T0018-INT-002`
- 正式验收入口：`../../01-验收标准.md`

## 3. 前置条件

- 环境前置：测试环境前端与后端服务可访问，并允许使用 Playwright 进行正式浏览器交互验收。
- 账号前置：需要合法测试环境登录态；当前缺少合法登录态，禁止记录或伪造账号、Token、Cookie、密码。
- 数据前置：使用 `03-测试数据模板.json` 中 `failedPageRegeneration` 数据，并准备可访问的失败状态自测报告。

## 4. 测试数据

```json
{
  "dataEntry": "03-测试数据模板.json#failedPageRegeneration",
  "buttonLabel": "重新生成自测报告",
  "expectedLoadingText": "重新生成中...",
  "pollIntervalSeconds": 3
}
```

## 5. 执行动作

| 步骤 | 动作 | 预期结果 |
| --- | --- | --- |
| 1 | 使用合法测试登录态进入失败状态自测报告页面 | 页面展示失败状态及“重新生成自测报告”按钮 |
| 2 | 点击“重新生成自测报告” | 按钮进入“重新生成中...”状态，避免重复提交 |
| 3 | 观察每 3 秒轮询及最终页面状态 | 页面按后端结果结束加载并展示新的报告状态 |

## 6. 期望结果

- 失败页正确展示“重新生成自测报告”按钮。
- 点击后按钮状态、重复提交限制和 3 秒轮询符合交互约定。
- 轮询结束后页面展示与后端生成结果一致的状态。

## 7. 脚本入口

- 自动化脚本：`Playwright 脚本待在测试环境补充`

- 结果输出位置：`04-测试执行结论.md`

## 8. 失败判定

- 失败页未展示重生成按钮，或按钮文案、加载状态不符合约定。
- 点击后发生重复提交、未按约定轮询，或最终状态与后端结果不一致。
- 缺少合法登录态时尝试伪造执行结果或写成通过。
