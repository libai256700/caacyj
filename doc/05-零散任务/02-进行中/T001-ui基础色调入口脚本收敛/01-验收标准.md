# T001-UI基础色调入口脚本收敛验收标准

## AC-001 任务载体

- 已建立 `00-任务计划.md`、`01-验收标准.md`、`02-任务产出/`。
- 计划中的任务状态与实际推进状态一致。

## AC-002 入口脚本职责

- `generate_base_tone_stage.py` 是 `000-基础色调` 阶段入口脚本。
- 入口脚本直接生成 `01-提示词.md` 和 `02-调用入参.json`。
- 入口脚本不得把已有 `02-调用入参.json` 当作待修复输入再自动改写。

## AC-003 产物顺序

- 阶段产物顺序固定为：
  1. `01-提示词.md`
  2. `02-调用入参.json`
  3. `03-生成图片.*`
  4. `04-图片说明.md`
- `03` 和 `04` 只在 image2 成功返回后生成或更新。

## AC-004 校验边界

- 校验只检查来源文件、字段、图片路径、产物结构和禁用字段。
- 校验失败时脚本必须报错停止。
- 校验不得自动修正或重写正式产物。

## AC-005 技能边界

- UI skill 负责组织提示词、生成调用入参、调用 image2、沉淀阶段产物。
- image2 skill 仍只负责底层生图调用，不反向管理 UI 阶段产物。
- skill 正文、脚本行为和示例口径保持一致。

## AC-006 验证与提交

- 已运行脚本级验证或目录规范检查。
- 已记录验证结果。
- 检查通过后，变更已提交并推送远程；如 image2 上游失败，需说明失败属于外部渠道问题还是脚本问题。
