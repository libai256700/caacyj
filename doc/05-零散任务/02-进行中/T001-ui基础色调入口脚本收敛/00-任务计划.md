# [零散任务计划]T001-UI基础色调入口脚本收敛

## 1. 任务信息

- 任务ID：`T001`
- 任务名称：UI基础色调入口脚本收敛
- 创建日期：`2026-05-11`
- 当前状态：`待用户审核`
- 分支引用：`沿用当前工作分支`
- 合并状态：`不涉及独立分支合并`
- 分支处置：`不涉及独立分支删除`

## 2. 任务目标

1. 修正企业级 UI 设计生成 skill 中 `000-基础色调` 阶段入口脚本的职责边界。
2. 让阶段入口脚本按顺序直接生成 `01-提示词.md`、`02-调用入参.json`，并在 image2 成功返回后生成 `03-生成图片.*`、`04-图片说明.md`。
3. 明确校验只负责检查来源与产物，不得自动修正或改写 `02-调用入参.json`。

## 3. 任务范围

- 包含：
  - 更新 `00-1800-ui-design-generation` 的 skill 规范。
  - 更新 `generate_base_tone_stage.py` 及其直接相关脚本。
  - 对飞行学院当前 `000-基础色调` 阶段重新执行脚本并检查产物结构。
- 不包含：
  - 修改 image2 底层远程 API 调用协议。
  - 重新设计飞行学院页面视觉方案。
  - 处理 image2 上游渠道不可用、额度或权限问题。

## 4. 统一原则

- 入口脚本负责一次性生成标准产物，不把 `02-调用入参.json` 当作待修复输入。
- `02-调用入参.json` 是 UI skill 调用 image2 的脚本级入参快照，必须由阶段入口脚本直接写出。
- 校验只允许检查缺失、非法字段、文件不存在和产物不齐；发现问题必须报错停止，不得自动改写正式产物。
- 实际生图仍由 `00-1700-image2-api-generation` 承担，UI skill 不直接调用内置生图工具。
