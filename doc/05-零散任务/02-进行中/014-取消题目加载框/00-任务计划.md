# [零散任务计划]T0014-取消题目加载框

> 本文档是当前零散任务推进的唯一正式计划入口。
> 未先建立或更新本文前，不得直接开始分析、改写、修复、验证、验收结论回写或归档。
> 本文档统一承载任务目标、正式验收入口、阶段任务总表、任务详情、门禁和人工审核闭环。正式验收标准不在这里定义，统一维护在 `01-验收标准.md`。

## 1. 任务信息

- 任务ID：`T0014`
- 任务名称：取消题目加载框
- 创建日期：`2026-08-20`
- 当前状态：`进行中`
- 分支引用：`沿用当前工作分支`
- 合并状态：`不涉及独立分支合并`
- 分支处置：`不涉及独立分支删除`

## 2. 任务目标

1. 统一取消前端在自测、考题、逐题、章节测试加载题目时显示的加载框。
2. 保留题目数据加载和页面状态流转，仅移除阻断用户操作的加载框展示，并确保四类入口行为一致。

## 3. 任务范围

- 包含：
- 自测、考题、逐题、章节测试四类题目加载流程中的加载框触发与关闭逻辑。
- 相关正式页面/组件的最小代码调整及局部回归验证。
- 不包含：
- 题目接口、题目排序、答题判分、提交逻辑和其他非加载框交互改造。
- `uni_modules/**` 三方包目录。

## 4. 统一原则

- 先读任务详情：阶段任务总表只做导航；真正实施前，必须先阅读对应任务详情。
- 计划启动门禁：只要 `01-验收标准.md` 未收口、阶段任务总表未补齐或当前任务没有任务详情，任何实施任务都不得进入 `进行中`。
- 正式验收承载位置：正式验收标准统一写到 `01-验收标准.md`；`00-任务计划.md` 只保留验收入口和状态门禁，不平行定义第二套正式验收标准。
- 未通过场景门禁：只要正式验收项仍有 `未通过`，不得把任务状态改为 `已完成`。
- 人工审核门禁：只有“独立验收通过 + 用户明确审核通过”同时满足后，才允许执行归档和状态回写。
