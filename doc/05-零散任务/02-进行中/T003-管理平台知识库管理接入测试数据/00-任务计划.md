# T003-管理平台知识库管理接入测试数据任务计划

## 1. 任务信息

- 任务ID：`T003`
- 任务名称：管理平台知识库管理接入测试数据
- 创建日期：`2026-06-15`
- 当前状态：`进行中`
- 分支引用：`沿用当前工作分支`
- 合并状态：`不涉及独立分支合并`
- 分支处置：`不涉及独立分支删除`

## 2. 任务目标

1. 查清管理平台“知识库管理”页面对应的数据表与字段映射。
2. 在非生产确认范围内补齐两条知识库数据：`云技科技原知识库`、`考试知识库`，状态均为启用。
3. 为管理平台知识库管理页面补齐“测试”操作：可输入问题、调用对应知识库接口，并弹框展示返回结果。

## 3. 任务范围

- 包含：
  - 定位管理平台知识库管理页面、接口与数据库表。
  - 补齐必要的数据初始化或脚本资产。
  - 修改管理平台页面操作列的测试交互。
  - 执行必要的本地构建、静态检查或页面验证。
- 不包含：
  - 直接操作生产数据库。
  - 修改 `uni_modules/**` 三方包。
  - 改造 fly-llm 知识库服务内部逻辑。

## 4. 统一原则

- 数据写入前必须确认当前连接不是生产库，且连接入口来自项目正式记录或本地配置。
- 若正式数据库连接记录缺失或指向生产，只允许产出 SQL/脚本和影响说明，不直接执行写入。
- 前端测试按钮必须区分两条知识库的真实接口目标，不得用假数据冒充真实调用。
- 所有检查通过后按项目规则提交；若存在远程仓库，则继续推送。
