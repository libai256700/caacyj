## 2. 前后端实现契约

- 岗位列表页顶部新增三个自绘下拉筛选：关键词、地域、工资区间。
- 关键词选项为 `全部 / 飞手类 / 工程师类 / 教培类 / 其他类`，请求参数映射为 `name`；前三类真实查询词分别为 `飞手 / 工程师 / 教培`，`其他类` 使用 `__other__` 哨兵值。
- 地域选项为 `全部 / 省份`，请求参数映射为 `workArea`。
- 工资区间选项为 `全部 / 0-3000 / 3000-5000 / 5000-10000 / 10000-30000 / 30000-200000`，请求参数映射为 `salaryRange`。
- 任一筛选变化后，前端按原分页链路重置到第一页；后续滚动翻页继续携带已选筛选条件。
- 原有 `keyword` 参数保持不变，未选新增筛选项时接口继续走原分页契约。

## 3. 后端过滤规则

- `name` 使用岗位名称包含匹配；`__other__` 表示排除名称中包含 `飞手 / 工程师 / 教培` 的岗位，空值和空白名称归入其他类。
- `workArea` 使用省份别名匹配，当前明确覆盖省名本体、去后缀简称、各省会城市，并覆盖现有样例 `武汉市洪山区 -> 湖北省`、`西安 -> 陕西省`。
- `salaryRange` 先把岗位自由文本解析成月薪区间，再按闭区间交集规则过滤：
  - 支持纯数字区间，如 `7000-14000`
  - 支持 `K/k` 与共享单位写法，如 `8-12K`、`5-20K`
  - 支持 `万` 与共享单位写法，如 `0.8-1.2万/月`
  - 支持边界相等命中
- `面议`、空值、无法解析、按天/小时/年薪表达在选定工资区间时排除
- 多条件之间使用 AND 组合。
- 当存在 `name / workArea / salaryRange` 任一新增筛选项时，后端先取符合基础条件的数据，再做内存过滤与手动分页切片，保证 `total` 与当前页列表一致。
