# T0015 综合考试后端报错修复实施记录

## 1. 真实调用链

- 前端入口：考试模式页点击“综合考试”，调用 `POST /app-api/yj/practices/{practiceId}/start/comprehensive-exam`
- 后端入口：`FrontPracticeController.startComprehensiveExam`
- 服务链路：`FrontPracticeServiceImpl.startComprehensiveExam -> FrontPracticeBatchService.startComprehensiveExam -> FrontPracticeBatchService.startBatch`
- 失败点：`startBatch` 构造 `UserPracticeExercisesRecordDO` 后执行 `userPracticeExercisesRecordMapper.insert(record)`，写入 `field_type` 时触发 `MysqlDataTruncation`

## 2. 根因证据

- 异常原文显示：`FrontPracticeBatchService.startBatch` 插入记录时报 `Data too long for column 'field_type' at row 1`
- 正式库表定义显示 `field_type` 为 `varchar(10)`：
  - `code/develop/yunjikeji-admin-server/doc/数据库表结构说明.md`
  - `doc/02-版本迭代/03-进行中版本/20260601000000-vphase1-initial-delivery/050-执行脚本/20260608-yj-admin-business-tables.sql`
- 综合考试路径原先把 `field_type` 固定写成 `comprehensive-exam`，长度 18
- 项目现有前端样式和既有预检资料都已使用 10 位编码 `comprehens` 作为综合类标识，说明不需要扩列，只需要修正错误业务值

## 3. 修改内容

- `code/develop/yunjikeji-admin-server/yunjikeji-admin-server/src/main/java/com/huiyitech/app/practice/service/FrontPracticeBatchService.java`
  - 将综合考试 `COMPREHENSIVE_EXAM_FIELD_TYPE` 从 `comprehensive-exam` 改为 `comprehens`
- `code/develop/yunjikeji-admin-server/yunjikeji-admin-server/src/main/java/com/huiyitech/app/practice/service/FrontPracticeServiceImpl.java`
  - 同步综合考试常量为 `comprehens`，保持服务层口径一致
- `code/develop/yunjikeji-admin-server/yunjikeji-admin-server/src/test/java/com/huiyitech/app/practice/service/FrontPracticeBatchServiceContractTest.java`
  - 补充综合考试落库断言：`record.fieldType == "comprehens"` 且长度不超过 10
