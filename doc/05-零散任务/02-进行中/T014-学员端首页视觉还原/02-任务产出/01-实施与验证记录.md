## 1. 实施范围

- 正式页面：`code/develop/yunjikeji/src/pages/home.vue`

- 正式视觉资产：
  - `src/static/home/student-home-reference.jpg`

- 用户目标图：`00-目标参考图.jpg`，原始尺寸 `852x1846`

## 2. 复用盘点与实现选择

- 第三方组件：项目已安装 `@climblee/uv-ui`，现有组织绑定弹窗和自测重置弹窗继续沿用；本次没有需要新建的弹层、标签、切换条或表单交互。
- 项目组件：继续复用唯一正式底栏 `HomeProfileTabBar`，通过 `student-home` 视觉变体承接目标图底栏，未复制导航逻辑。
- 首页实现：沿用项目原有“正式参考视觉 + 真实业务热区”结构，替换目标视觉并校准热区；目标图中的复杂实物插画没有可独立复用的项目组件，拆成 CSS 或重新绘制会降低还原度并产生第二套视觉资产，因此不从零重绘。
- 功能边界：首页 `<script setup>` 的请求、状态、弹窗和路由处理逻辑保持原样，只把两项展示标签调整为目标图中的“模拟考试”和“岗位信息”。

## 3. 视觉实现

- 将旧橙色无人机教育首页替换为用户提供的蓝白行业先锋岗位 AI 职教首页。
- 内容画布按目标图底栏起始位置收口为 `852 / 1728`，固定底栏使用同一目标图最后 `118px` 的裁切资产。
- 重定位以下业务热区：开始测评、评测结果、逐题练习、章节测试、模拟考试、开始错题练习、岗位信息、联系客服。
- 底栏仍由共享组件提供首页、AI助手、我的三个真实入口；只有学员首页选择蓝色目标视觉，其他使用方保持默认视觉。
- 页面背景统一为目标图的冷白色，三视口均由稳定宽高比例约束，不使用视口宽度驱动字体缩放。
