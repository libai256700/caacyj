## 缺失清单结论

- `category_id = 13` 的 19 道题来自调查问卷导入，导入策略为“不设置标准答案”，不是程序迁移丢字段。
- `category_id = 1` 的题目 `id = 28` 是普通题，主表正确答案为 `C`，但当前选项只有 `A/B`，选项本身缺失 `C`。该题不能通过简单把 A 或 B 标为正确来修复，需要补齐真实 C 选项内容后再执行数据修复。

## yunjikeji-server 核对

`yunjikeji-server` 学员端练习链路使用：

- `yk_question.correct_answer`
- `yk_question_option`

并未直接依赖后台表 `yj_practice_exercises_answer.is_correct` 判题。`yk_question_option` 当前也存在同一条普通题 `id = 28` 选项缺失问题：主表 `correct_answer = C`，但选项只有 `A/B`。
