# 练习题题型显示修复记录

## 问题

练习题管理-题目管理列表中，“题型”列显示为原始值 `2`，未显示为业务题型名称。

## 原因

前端列表按 `yj_practice_question_type` 字典渲染题型。测试库中练习分类 `catalog_type = 0` 的 1473 道题仍保留历史题型值 `2`，而当前字典值为 `single_choice`、`multiple_choice`、`judge`、`text`，导致字典无法命中，只能显示原始值。

已有脚本 `yunjikeji-admin-server/sql/mysql/20260610_yj_practice_question_type_dict.sql` 中明确历史映射：`2 -> single_choice`。

## 执行

执行脚本：

- `execute_yj_practice_question_type_normalize_20260611.py`

备份表：

- `yj_practice_exercises_qtype_bak_20260611185026`：1473 行
- `yj_practice_answer_qtype_bak_20260611185026`：4406 行
- `yj_practice_answer_child_qtype_bak_20260611185026`：0 行

回滚入口：

- `rollback_yj_practice_question_type_normalize_20260611.sql`

## 结果

- `yj_practice_exercises.question_type = '2'`：1473 -> 0
- `yj_practice_exercises_answer.question_type = '2'`：4406 -> 0
- `yj_practice_exercises_answer_child.question_type = '2'`：0 -> 0
- 截图中样本题 `2729-2738` 已全部变为 `single_choice`，可命中字典显示为“单选题”。
