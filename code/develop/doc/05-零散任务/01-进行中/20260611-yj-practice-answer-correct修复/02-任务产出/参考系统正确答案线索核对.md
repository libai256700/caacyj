# 参考系统正确答案线索核对

## 核对范围

- 参考系统代码目录：`E:\huiyitechworkspace\feixingxueyuan\code\develop\yunjikeji-server`
- 核对数据库：测试库 `yunjikeji`
- 目标问题：后台题目管理可选项中缺少“是否正确”标记的题目，能否从参考系统恢复正确答案线索。

## 代码线索

参考系统学生端练习判题主链路使用 `yk_question.correct_answer`：

- `PracticeService.submitAnswer` 读取题目后，将用户提交答案和 `question.correctAnswer` 统一标准化，再比较是否一致。
- `yk_practice_record.standard_answer_snapshot` 写入的是 `question.correctAnswer`。
- `yk_question_option.is_correct` 在 `PracticeRepository.findOptionsByQuestionId` 中会被读取，但当前提交判题主路径没有依赖该字段。
- 选项优先从 `yk_question_option` 读取；如果选项表没有数据，才 fallback 到 `yk_question.options_json`。

结论：参考系统的标准答案主线索是 `yk_question.correct_answer`，辅助线索是 `yk_question.answer_json.correctAnswer` 和 `yk_question.options_json`。

## 判断

1. “正确答案显示为停用”是前端把 `switch` 类型统一渲染成“启用/停用”的显示问题，已修复为 `是/否`。
2. “每个题目里没有答案是正确答案”不是全量问题；全量统计中大部分题目已经有 `is_correct = 1`。
3. 当前缺失正确标记的 20 题里，19 题是评估问卷，没有参考系统标准答案，不应补正确答案。
4. 题目 28 是迁移/解析缺失：正确答案和 C 选项内容保留在 `yk_question` 主表 JSON 中，但没有同步进入 `yk_question_option` 和 `yj_practice_exercises_answer`。
