## 任务目标

定位题目管理“配置可选项”弹窗中“正确答案”列显示为“停用”的原因，核对 `yunjikeji-server` 中题目与答案字段逻辑、迁移后数据库真实状态和后台页面展示映射，确认是迁移数据缺失还是程序映射问题，并完成最小范围修复。

## 任务范围

- 代码范围：`yunjikeji-server` 中题目、答案、可选项相关接口和数据对象。
- 展示范围：后台题目管理“配置可选项”弹窗及其 API 映射。
- 数据范围：测试库中 `yj_practice_exercises`、`yj_practice_exercises_answer`、必要时包含 `yj_practice_exercises_answer_child`。
- 样本范围：截图中的题目 `#2768` 及必要的全量统计。
- 禁止范围：不操作生产库；不修改 `uni_modules/**`；不引入假数据；不改与题目答案无关的业务逻辑。

## 统一原则

1. 先核对真实接口字段、前端显示字段和数据库字段，不凭截图直接下结论。
2. 只读 SQL 可直接执行；涉及 DML 必须脚本化、备份、可回滚、执行后校验。
3. 若根因是前端字典映射错误，修前端显示映射；若根因是后端字段含义错误，修后端返回字段；若根因是迁移数据缺失，先提供数据修复脚本。
4. 修复后必须覆盖样本题 `2768`，并补充全量“每题至少有正确答案标记”的数据核对结果。
5. 不把状态字段 `status` 与是否正确字段 `is_correct` / `correct` 混用。
