## 任务目标

在测试库 `yunjikeji` 中，将当前练习考题相关数据统一归属到租户 `1`，覆盖题目主表、题目可选项表和题目二级选项表，并保留执行前校验、备份、执行脚本、执行后校验和回滚入口。

## 任务范围

- 处理表：`yj_practice_exercises`
- 处理表：`yj_practice_exercises_answer`
- 处理表：`yj_practice_exercises_answer_child`
- 只处理字段：`tenant_id`
- 目标值：`1`
- 数据库入口：`yunjikeji-admin-server/yunjikeji-admin-server/src/main/resources/application-local.yaml` 中的测试库连接配置
- 只处理测试库，不处理生产数据库
- 不更新 `uni_modules/**`
- 不修改业务代码
- 自测题表 `yj_assessment_question`、`yj_assessment_answer` 当前无数据，仅作为只读校验参考，不执行 DML

## 统一原则

1. 写操作必须脚本化，禁止直接执行裸 SQL。
2. 执行前必须查询每张表总行数、已为 `1` 的行数、非 `1` 或空值行数和 tenant 分布。
3. 执行前必须创建本次运行唯一备份表，记录所有将被修改行的 `id` 和原 `tenant_id`。
4. 执行后必须确认三张目标表中 `tenant_id <> 1 OR tenant_id IS NULL` 的记录数均为 `0`。
5. 必须提供回滚脚本；回滚依赖执行前备份表。
6. 正式连接入口缺失、连接失败、备份失败或执行后校验失败时停止执行并回滚事务内 DML。
