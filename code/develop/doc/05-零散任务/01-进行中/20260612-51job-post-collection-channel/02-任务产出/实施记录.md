## 实现说明

- 新增前程无忧岗位采集渠道实现 `Job51PlatformPostCollectServiceImpl`，后端渠道 code 为 `51job`。
- 前程无忧实现复用 `AbstractRecruitWebsitePostCollectService`，使用真实搜索页 `https://we.51job.com/pc/search?keyword=%s&searchType=2&sortType=0` 访问结果，并解析页面卡片或内嵌 JSON 片段中的岗位名称、公司名称、薪资范围、工作区域、详情地址等字段。
- 外部访问失败、返回空页面或页面结构不匹配时，前程无忧实现记录清晰日志并返回空结果，不使用假数据冒充真实采集结果。
- `PostPlatformCollectServiceFactory` 已注册 `Job51PlatformPostCollectServiceImpl`，保证字典 value `51job` 可路由到对应后端实现。
- `BossZPPlatformPostCollectServiceImpl` 已置空，不再继承网页采集实现，不再执行 BOSS 直聘真实访问和解析；`collect` 仅记录“不予实现”日志并返回 `Collections.emptyList()`。

## 风险与边界

- 参考技能包没有前程无忧专属实现，本次按通用真实网页采集模式接入；前程无忧若强依赖动态渲染或反爬校验，服务端 `RestTemplate` 直连可能返回空结果。
- 前程无忧页面结构若调整，正则解析可能无法命中；该场景会保留为空结果边界，不生成伪造岗位。
- 当前工作区存在任务目录及若干 `dump.rdb`、图片等既有未跟踪文件，本次未处理这些无关文件。
