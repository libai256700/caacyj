# 事实清单

## 现有链路

- 渠道接口：`yunjikeji-admin-server/yunjikeji-admin-server/src/main/java/com/huiyitech/postcollect/service/IPostPlatformCollectService.java`，定义 `getPlatformSource()` 和 `collect(PostCollectTaskDO task)`。
- 渠道工厂：`yunjikeji-admin-server/yunjikeji-admin-server/src/main/java/com/huiyitech/postcollect/service/PostPlatformCollectServiceFactory.java`，构造方法内手工注册渠道实现。
- 现有渠道实现：
  - `BossZPPlatformPostCollectServiceImpl.java`，渠道 code 为 `boss_zhipin`。
  - `LiepinPlatformPostCollectServiceImpl.java`，渠道 code 为 `liepin`。
  - `ZhilianPlatformPostCollectServiceImpl.java`，渠道 code 为 `zhilian`。
  - `GuopinPlatformPostCollectServiceImpl.java`，渠道 code 为 `guopin`。
- 通用网页采集抽象：`AbstractRecruitWebsitePostCollectService.java`，负责关键词拆分、GET 请求、HTML 交给子类解析。
- 通用字段构造：`AbstractPostPlatformCollectService.java`，`buildPost` 生成 `PostCollectDO`，默认 `publishDate=LocalDate.now()`、`status=true`。
- 采集入口：
  - 管理端立即采集接口：`POST /admin-api/postcollect/post-collection-task/collect-now`。
  - 定时入口：`PostCollectionTaskScheduleJob` 调用 `collectDueTasks("system")`。
  - 核心链路：`PostCollectionTaskService.collectTask(...)` 创建任务实例、保存岗位实例、合入正式岗位表。

## 风险

- 参考技能包没有前程无忧专属实现，前程无忧页面/API 结构需实施时自行确认。
- 当前 Java 网页渠道多依赖 HTML 正则解析，若目标站动态渲染或反爬增强，可能返回空结果。
- 现有 SQL 脚本中文在终端显示可能乱码，实施时应只做最小增量，避免重写整文件。
