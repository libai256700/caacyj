# 前程无忧岗位采集渠道接入任务计划

## 任务目标

在管理平台采集配置的采集来源字典中新增“前程无忧”渠道，并在后端岗位采集链路中实现该渠道。实现需参考 `E:\huiyitechworkspace\zhengjiacaiji\岗位采集技能包` 的前程无忧采集逻辑，接入现有采集任务、采集实例、岗位实例入库和合入流程。同时将 `BossZPPlatformPostCollectServiceImpl` 的 BOSS 直聘实现置空，不再执行 BOSS 直聘真实采集。

## 任务范围

1. 读取现有岗位采集服务结构、渠道工厂或注入方式、字典初始化脚本、采集任务配置和相关测试入口。
2. 读取 `E:\huiyitechworkspace\zhengjiacaiji\岗位采集技能包` 中前程无忧采集逻辑，形成字段映射和失败边界。
3. 新增“前程无忧”采集来源字典脚本，确保管理平台下拉框出现该项，且脚本幂等、可校验。
4. 新增或接入前程无忧渠道后端实现，返回真实解析字段，不用假数据冒充真实采集。
5. 将 BOSS 直聘实现置空，不予实现，并保持渠道调用失败边界清晰。
6. 执行必要编译、测试或局部验证，记录结果。
7. 检查通过后提交并推送远程；最终等待用户人工审核。

## 统一原则

1. 不修改 `uni_modules/**`。
2. 不直接操作生产数据库；字典新增只落 SQL 脚本，不直接执行生产写操作。
3. DML 脚本必须幂等，包含执行后校验入口。
4. 参考技能包只作为采集逻辑依据，不复制无关临时产物、cookies 或结果文件。
5. BOSS 直聘置空必须可读可追踪，不能继续伪装为已实现真实采集。
6. 沿用当前工作分支，不新建独立分支。
