## 实施说明

- 前端协议管理页使用的是 `yunjikeji-admin-ui/src/views/yj/resource/index.vue` 的通用 CRUD 页面。
- 该页面对 `type: 'select'` + `dictType` 字段统一走 `getFieldOptions` 渲染下拉，提交时统一走 `sanitizeFormData` 按字段值原样出参。
- 因此本次只需在 `config.ts` 把协议管理 `type` 字段接入字典，即可保证：
  - 新增页显示字典下拉
  - 搜索条件显示字典下拉
  - 表格和详情使用字典 label 展示
  - 保存时提交字典 `value`，不提交中文 `label`
