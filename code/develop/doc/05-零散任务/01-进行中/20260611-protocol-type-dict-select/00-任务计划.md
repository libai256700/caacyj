# 协议类型字典下拉对接任务计划

## 任务目标

协议管理中的新增协议页面，`type` 字段由手工输入或静态值改为从系统字典获取的下拉框；字典值落库并覆盖：

- 培训协议：`01`
- 管理协议：`02`
- 设备协议：`03`
- 考试协议：`04`
- 训练协议：`05`

## 任务范围

1. 确认当前协议管理新增页面、协议保存接口和字典表结构。
2. 新增或补齐协议类型字典 SQL，保证可重复执行或具备明确插入边界。
3. 将新增协议页面 `type` 字段对接字典下拉取值。
4. 完成必要的构建、静态检查或局部验证。
5. 提交代码；如存在远程仓库，推送远程。

## 统一原则

1. 不修改 `uni_modules/**`。
2. 不直接操作生产数据库；本次只提交随项目管理的 SQL 或初始化脚本。
3. 优先复用项目现有字典接口、字典组件和表单模式。
4. 沿用当前工作分支，不创建独立分支，不涉及独立分支合并或删除。

## 任务详情

### T01 现状定位与方案确认

- 实施标准：定位协议新增页面、协议 `type` 字段保存链路、字典接口和字典表初始化脚本位置。
- 对应技能或责任：实施代理。
- 交付物：定位结论写入 `02-任务产出/实施记录.md`。
- 关联验收项：A1、T1、T2、T3。
- 结果记录入口：`02-任务产出/实施记录.md`。

### T02 字典数据脚本落位

- 实施标准：按项目现有脚本风格插入协议类型字典，字典项 value 与名称符合用户指定内容。
- 对应技能或责任：实施代理。
- 交付物：SQL 或初始化脚本变更。
- 关联验收项：T2。
- 结果记录入口：`02-任务产出/实施记录.md`。

### T03 新增协议页面对接字典下拉

- 实施标准：新增协议页面 `type` 使用字典下拉；提交保存时仍传递业务要求的 value。
- 对应技能或责任：实施代理。
- 交付物：页面或组件代码变更。
- 关联验收项：A1、T1、T3。
- 结果记录入口：`02-任务产出/实施记录.md`。

### T04 验证与结果记录

- 实施标准：执行与本次变更相关的可用验证；若受环境限制无法执行，记录限制和替代核对证据。
- 对应技能或责任：独立验收代理。
- 交付物：`02-任务产出/验证记录.md`。
- 关联验收项：A1、T1、T2、T3、C1。
- 结果记录入口：`02-任务产出/验证记录.md`。

### T05 提交与推送

- 实施标准：确认工作区不包含 `uni_modules/**` 改动；提交本次任务相关文件；有远程仓库时推送。
- 对应技能或责任：主代理。
- 交付物：Git 提交与推送记录。
- 关联验收项：C1。
- 结果记录入口：`02-任务产出/提交记录.md`。

### T06 用户审核

- 实施标准：正式验收通过后等待用户明确审核。
- 对应技能或责任：用户。
- 交付物：用户审核结论。
- 关联验收项：C1。
- 结果记录入口：本文件。
