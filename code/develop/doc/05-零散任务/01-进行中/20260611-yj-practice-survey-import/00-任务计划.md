## 任务目标

使用 chrome-devtools 访问 `https://120.79.4.220/`，整理该系统中的调查问卷数据，并将问卷分类与题目数据导入当前系统 `yj_practice` 系列表；其中 `yj_practice_category` 新增一条“入行专属评估”分类，调查问卷问题全部关联到该分类下。

## 任务范围

- 采集范围：`https://120.79.4.220/` 中可访问的调查问卷题目、选项、答案或评分规则等与问卷入库直接相关的数据。
- 入库范围：当前系统数据库中的 `yj_practice` 系列表，至少包含 `yj_practice_category` 和调查问卷题目落库所需的关联表。
- 分类要求：`yj_practice_category` 插入一条“入行专属评估”分类，全部导入题目关联到该分类。
- 产出要求：保留采集结果、表结构核对记录、执行 SQL 或脚本、执行记录、回滚入口和验收记录。
- 禁止范围：不操作生产数据库；不修改 `uni_modules/**`；不使用假数据冒充真实问卷数据；不直接改业务代码，除非入库脚本必须落地。

## 统一原则

1. 数据来源必须来自 `https://120.79.4.220/` 的真实页面或真实接口响应。
2. 写入数据库前必须确认目标数据库连接入口、目标表结构、字段含义和必要默认值。
3. 写入数据库必须脚本化或 SQL 文件化，禁止只靠临时命令完成。
4. 执行前必须保留去重或幂等策略，避免重复插入分类或重复题目。
5. 执行后必须核对分类存在、题目数量正确、题目与分类关联正确。
6. 如连接入口、账号权限、页面鉴权或目标库环境缺失，立即停止并请求用户补充。
