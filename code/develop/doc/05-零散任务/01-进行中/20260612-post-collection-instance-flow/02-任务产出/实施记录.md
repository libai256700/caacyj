# 实施记录

## 后端

- `yj_post` 实体改为非租户表，移除 `company_id` 字段。
- 新增 `yj_post_collection_task_instance` 与 `yj_post_instance` 对应 DO/Mapper。
- 立即采集和定时采集统一进入 `PostCollectionTaskService.collectTask`。
- 启动采集时创建任务实例，状态为 `1`。
- 采集结果先写入 `yj_post_instance`。
- 合入时按 `name + company_name + salary_range + work_area` 去重，重复数据不写入 `yj_post`。
- 合入完成后任务实例状态置为 `3`。
- 新增猎聘、智联、国聘平台服务，并接入平台工厂。

## 前端/后台资源

- 岗位主表配置移除 `company_id`，改为展示 `company_name`。
- 采集配置关联内容由旧执行日志改为采集实例。
- 新增采集任务实例、采集岗位实例只读资源配置。

## 采集时间丢失

- 已核对前端字段为 `collection_time`，后端 `PostCollectTaskDO.collectionTime` 为 `Timestamp`。
- 通用资源服务的字段转换支持下划线转驼峰和 `Timestamp.valueOf`，保留 `collection_time` 为可写字段。
- 前端通用资源表单提交时按字段类型清洗 `date/datetime`，统一提交 `YYYY-MM-DD HH:mm:ss`。
- 后端通用采集资源服务补充兼容 ISO 与带时区时间字符串，避免浏览器 Date 序列化格式导致采集时间转换失败。
- 新增和编辑采集配置均走同一 `sanitizeFormData` 与 `AbstractPostCollectResourceService` 转换链路。

## 用户补充：任务实例通用审计字段

- `PostCollectionTaskInstanceDO` 继承 `BaseDO`，包含创建人、创建时间、更新人、更新时间、删除标记。
- 正向 SQL 中 `yj_post_collection_task_instance` 已包含 `creator/create_time/updater/update_time/deleted`。
- 后台资源白名单只开放业务字段，审计字段由通用创建/更新逻辑维护。
