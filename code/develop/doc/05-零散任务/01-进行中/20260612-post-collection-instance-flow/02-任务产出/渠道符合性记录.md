## 结论

- 技能包推荐方案为 Playwright 浏览器自动化访问真实招聘站点，并明确 BOSS、猎聘、智联、国聘存在登录态和反爬依赖。
- 本次后端实现按技能包的四个平台真实搜索入口建立服务类，不生成假数据。
- 当前 Java 服务采用 HTTP 获取页面 + 页面结构解析方式，字段映射到 `name/company_name/salary_range/work_area/source_code/external_post_id/detail_url`。
- 若站点要求登录态、验证码或反爬拦截，服务会返回空结果或抛出真实访问异常；不会以假数据冒充采集结果。
