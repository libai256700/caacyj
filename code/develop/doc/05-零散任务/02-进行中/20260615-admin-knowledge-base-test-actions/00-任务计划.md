# 管理平台知识库管理测试入口任务计划

## 任务目标

确认管理平台“知识库管理”页面对应的真实数据库表，并在测试/开发环境中为该页面补充两条启用状态知识库记录：

- 云技科技原知识库：操作列提供“测试”按钮，输入问题后请求 `http://127.0.0.1:5001/api/ask?q=XXXX`，并展示返回结果。
- 考试知识库：操作列提供“测试”按钮，输入问题后请求 fly-llm 的知识库接口（APP 错题 AI 解析），并展示返回结果。

## 任务范围

1. 定位管理平台知识库管理页面、接口和对应数据库表。
2. 核对数据库连接正式记录，仅允许在开发/测试环境执行写入；不得直接写生产库。
3. 按真实表结构插入或幂等补齐两条启用状态知识库数据。
4. 调整管理平台页面操作列，复用现有弹框、输入框、按钮、消息提示和请求封装。
5. 对两个测试入口分别完成请求参数、返回展示和异常提示处理。
6. 执行可用的静态检查、构建或局部验证，并记录结果。
7. 检查暂存区不包含 `uni_modules/**` 后提交；有远程仓库时继续推送远程。

## 不在范围

- 不改动生产数据库。
- 不新增或修改 `uni_modules/**`。
- 不用假数据冒充真实接口结果；外部接口不可用时必须展示明确失败信息并记录限制。
- 不改变知识库管理页面的主数据模型和权限体系，除非定位后证明现有模型缺失必要字段。

## 统一原则

1. 先确认表、接口、连接入口，再实施数据和页面改动。
2. 数据写入必须可复核、可重跑，优先使用幂等 SQL 或现有后端接口。
3. 页面测试按钮只作为当前知识库行的操作，不影响列表查询、分页、启停和其他已有操作。
4. fly-llm 接口必须复用项目已有配置或服务封装；正式记录缺失时停止猜测并请求用户补充。
