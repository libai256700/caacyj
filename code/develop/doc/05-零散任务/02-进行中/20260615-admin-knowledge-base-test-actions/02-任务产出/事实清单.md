# 事实清单

## 页面与接口

- 管理平台“知识库管理”页面使用通用资源页：`yunjikeji-admin-ui/src/views/yj/resource/index.vue`。
- 页面配置位于：`yunjikeji-admin-ui/src/views/yj/resource/config.ts`，资源键为 `knowledge-base`。
- 前端通用 API 封装位于：`yunjikeji-admin-ui/src/api/yj/index.ts`。
- `knowledge-base` 未配置特例 endpoint，因此实际管理接口为：
  - `GET /yj/knowledge-base/page`
  - `GET /yj/knowledge-base/get?id=...`
  - `POST /yj/knowledge-base/create`
  - `PUT /yj/knowledge-base/update`
  - `DELETE /yj/knowledge-base/delete?id=...`

## 后端与表

- 通用后端入口：`yunjikeji-admin-server/yunjikeji-admin-server/src/main/java/cn/iocoder/yudao/server/controller/admin/yj/YjAdminController.java`。
- 通用服务：`yunjikeji-admin-server/yunjikeji-admin-server/src/main/java/cn/iocoder/yudao/server/service/yj/YjAdminService.java`。
- 表注册：`yunjikeji-admin-server/yunjikeji-admin-server/src/main/java/cn/iocoder/yudao/server/service/yj/YjAdminTableRegistry.java`。
- 资源 `knowledge-base` 对应主表：`yj_knowledge_base`。
- 主表可写字段：`name`、`item_count`、`status`、`tenant_id`。
- 通用查询依赖字段：`id`、`create_time`、`update_time`、`deleted`。
- 子表资源 `knowledge-item` 对应表：`yj_knowledge_item`，外键 `knowledge_base_id`。
- 状态字段 `status` 在该通用资源中按 bit/boolean 使用，启用为 `b'1'` / `true`。

## fly-llm 接口

- fly-llm 对外 Controller：`fly-llm/src/main/java/com/flyllm/examkb/controller/OpenAiCompatibleController.java`。
- 接口路径：`POST /v1/chat/completions`。
- 默认端口：`fly-llm/src/main/resources/application.yml` 中 `server.port: 8088`。
- 管理平台测试入口使用：`http://127.0.0.1:8088/v1/chat/completions`。
- 请求体使用 OpenAI 兼容结构：`model`、`stream`、`messages`、`metadata.question`。
- 火山知识库底层检索实现位于：`fly-llm/src/main/java/com/flyllm/examkb/service/impl/VolcKnowledgeBaseService.java`。
