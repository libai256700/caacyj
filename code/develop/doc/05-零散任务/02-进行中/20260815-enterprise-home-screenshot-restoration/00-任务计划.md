## 2. 任务目标

## 3. 任务范围

- 包含：企业端首页、企业身份路由/状态分流、公共底部导航的轻扩展复用、必要静态视觉素材、尺寸与交互验证。
- 不包含：学员端首页视觉重设计、企业审核/注册流程改造、后端 API 协议变更。

## 4. 统一原则

- 先读任务详情；正式验收标准统一写入 `01-验收标准.md`。
- 企业与学员必须以 `appState.loginIdentity` 或项目既有等价入口明确分流。
- 优先复用项目已有正式组件与静态资产，不建立平行的底部导航实现。
- 只要正式验收项仍有未通过，不得将任务标记为已完成。
- 仅在独立验收通过且用户明确审核通过后归档。
