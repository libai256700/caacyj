# 企业端首页实施记录

## 实施结果

- `src/pages/home.vue`：在统一首页入口按 `appState.loginIdentity` 分流，企业身份立即进入 `/pages/enterprise/students`，学员身份保持原首页。
- `src/pages/enterprise/students.vue`：按 852 x 1844 参考图重建为单列筛选卡、“加入申请”分组卡和待审核操作卡；保留真实列表、日期筛选、同意和拒绝交互。
- `src/components/HomeProfileTabBar.vue`：企业页直接复用学员端同一正式组件；点击首页时根据身份返回企业首页或学员首页。
- 新增三张由用户参考图精确裁切的非交互视觉资产：顶部主视觉、下半部水印场景、蓝色学员头像。

## 验证记录

- `npm run type-check`：通过。
- `npm run build:h5`：通过。
- Playwright 426 x 922：企业 `/pages/home` 自动分流到 `/pages/enterprise/students`；无水平溢出。
- Playwright 交互：日期弹层可打开和确认；同意审核显示成功提示；AI 助手可进入；企业身份点击“首页”返回企业页。
- Playwright 390 x 844：学员身份仍留在 `/pages/home`，存在 3 个原学习内容板块，不存在企业申请分组。
- 最终视觉证据：`code/develop/yunjikeji/output/playwright/enterprise-home-final.png`。

## 边界说明

- 页面审核列表仍使用现有 `fetchCompanyStudentAudits` 和 `auditCompanyStudent` 入口，未改动后端协议。
- H5 模拟登录且服务不可用时，仅为 `h5-preview-` token 提供一条与参考图一致的预览数据；正式 token 仍显示真实错误和重试入口。
