## 2. 任务目标

1. 阅读并梳理项目现有 IM 实现，明确 APP 端、服务端、管理端与会话/消息数据之间的真实调用关系。
2. 给出学员和教员在 APP 中实现 IM 聊天的落地方案，并完成当前代码中“客服会话”相关的最小可交付实现或修复。

## 3. 任务范围

- 包含：现有 IM 代码阅读、客服会话入口/列表/消息链路实现或修复、关键接口和状态承接说明、验证记录、面向后续学员-教员 IM 的实现建议。
- 不包含：生产部署、生产数据变更、第三方 IM 厂商开通、未获确认的账号密钥配置、`uni_modules/**` 三方包改动。

## 4. 统一原则

- 以项目现有实现为准，优先复用已有 API、状态管理、页面结构和消息模型。
- 涉及鉴权、环境地址、账号密钥或平台权限时，只核对正式记录或现有配置，不凭印象猜测。
- 发现根因落在 `uni_modules/**` 时，只输出定位结论和影响说明，未经用户明确批准不修改。
- 客服会话实现必须能被真实接口或现有 mock/开发入口验证，不能用假静态数据冒充真实机制。
