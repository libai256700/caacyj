# yunjikeji-admin-server 启动说明

本文记录后端 `yunjikeji-admin-server` 的本地启动方式，重点包含 WSL Redis 和后端 Jar 的启动步骤。

## 1. 启动前确认

- JDK 8 已安装
- Maven 已安装
- 本地 MySQL 可访问
- WSL 中安装了 Redis

当前本地配置文件：

- `yunjikeji-admin-server/src/main/resources/application-local.yaml`
- 端口：`48080`
- Redis：`127.0.0.1:6379`
- 数据库：`114.111.30.111:13306/yunjikeji`

## 2. 启动 WSL 中的 Redis

当前项目本地配置把 Redis 指向 Windows 侧的 `127.0.0.1:6379`，实际 Redis 运行在 WSL 的 Ubuntu 里。

### 2.1 进入 WSL

```powershell
wsl -d Ubuntu
```

### 2.2 启动 Redis

如果已经有 Redis 在跑，先停掉再启动：

```bash
redis-cli -h 127.0.0.1 -p 6379 shutdown
```

如果 Redis 已安装为系统服务：

```bash
service redis-server start
```

如果服务命令不可用，也可以直接启动：

```bash
wsl -d Ubuntu sh -lc "redis-server --bind 0.0.0.0 --port 6379"
```

### 2.3 验证 Redis

```bash
redis-cli -h 127.0.0.1 -p 6379 ping
```

正常返回：

```text
PONG
```

### 2.4 查看监听端口

```bash
ss -ltnp | grep 6379
```

## 3. 启动后端 Jar

### 3.1 先打包

在项目根目录执行：

```powershell
mvn -pl yunjikeji-admin-server -am -DskipTests package
```

打包完成后会生成：

```text
yunjikeji-admin-server/yunjikeji-admin-server/target/yunjikeji-admin-server.jar
```

### 3.2 启动 Jar

```powershell
java -jar .\yunjikeji-admin-server\target\yunjikeji-admin-server.jar --spring.profiles.active=local
```

### 3.3 启动成功标志

- 日志出现 `Tomcat started on port(s): 48080`
- 日志出现 `Started YunjikejiAdminServerApplication`
- 访问健康检查返回 `UP`

健康检查地址：

```text
http://127.0.0.1:48080/actuator/health
```

## 4. 停止服务

### 4.1 停止 Jar

```powershell
Get-Process java | Stop-Process
```

如果只想停当前启动的那个进程，先用：

```powershell
Get-Process java
```

再按 PID 停掉。

### 4.2 停止 WSL Redis

```bash
redis-cli -h 127.0.0.1 -p 6379 shutdown
```

如果是服务方式启动，也可以在 WSL 中执行：

```bash
service redis-server stop
```

## 5. 常见问题

- 如果 Jar 启动时报 Redis 连接失败，先确认 WSL 里的 Redis 是否已启动
- 如果本地 `127.0.0.1:6379` 不通，检查 WSL 是否已经启动，以及 Redis 是否监听在 6379
- 如果后端启动成功但页面未通，优先确认 `48080` 端口是否被其他进程占用
