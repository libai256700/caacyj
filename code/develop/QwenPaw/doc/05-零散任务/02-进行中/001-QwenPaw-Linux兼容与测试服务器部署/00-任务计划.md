## 4. 统一原则

- 先读任务详情：阶段任务总表只做导航；执行前必须读取对应任务详情与 `01-验收标准.md`。
- 正式事实优先：服务器、账号、端口、目录、鉴权和服务入口只以开发中心正式记录为准；缺失、冲突或失效时停止并请求用户处理。
- 配置兼容：配置入口同时兼容 Windows 与 Linux；优先使用标准路径 API、环境变量和显式配置，不硬编码平台路径分隔符或本机绝对路径。
- 配置保护：本地 `workspaces` 和 `C:\Users\renquan\.qwenpaw` 在实施前后必须逐文件核对；不得将其中敏感配置提交到仓库或无授权复制到服务器。
- 本地运行环境：QwenPaw 的正式本地环境是 Conda 环境 `qwenpaw`；本地命令统一通过 `conda run -n qwenpaw ...` 执行，不重建或删除该环境，不用系统 Python 替代验证。
- 部署门禁：仅操作测试环境；部署和替换前必须备份远端现有程序与配置，明确回退入口；不直接操作生产数据库。
- 验收门禁：实施代理不得自验收；正式验收由新的独立验收代理完成；有未通过项时不得进入人工审核。
- 收口门禁：检查通过后必须形成 Git 提交并推送远端；只有“独立验收通过 + 用户明确审核通过”后才允许归档。
