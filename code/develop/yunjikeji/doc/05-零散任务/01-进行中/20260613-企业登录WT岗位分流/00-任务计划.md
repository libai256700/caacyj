# 企业登录 WT 岗位分流任务计划

## 任务目标

在管理平台后端新增 APP 企业登录辅助接口：根据企业登录手机号查询 `system_users.mobile`，读取用户 `post_ids` 关联 `system_post.code`，返回 APP 端是否包含 `WT` 岗位编码。APP 企业登录后先调用该接口；命中 `WT` 时按审核通过路径刷新 token 并进入消息页，未命中或查询不到时继续沿用现有 `auditStatus` 分流逻辑。

## 任务范围

- 后端：`FrontComanpanyAuditController` 增加 APP 接口，并补充必要 service/mapper 查询逻辑。
- 前端：企业登录流程新增岗位检查接口调用，并调整企业登录后的分流逻辑。
- 验证：通过静态检查、编译或可用测试验证接口路径、返回字段和前端分支。

## 不在范围

- 不变更生产数据。
- 不调整现有企业审核表结构。
- 不改变学员登录流程。
