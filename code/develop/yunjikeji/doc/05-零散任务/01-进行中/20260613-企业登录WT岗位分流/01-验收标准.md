# 企业登录 WT 岗位分流验收标准

## 验收项

1. 后端新增接口可由 APP 调用，入参为企业登录手机号，返回是否命中 `WT` 岗位编码。
2. 后端查询逻辑以 `system_users.mobile` 为用户匹配条件，以用户 `post_ids` 关联 `system_post.id` 并读取 `system_post.code`。
3. 当前端企业登录手机号命中 `WT` 岗位编码时，登录后执行刷新 token，并进入消息页；消息页继续调用 `GET /app-api/yj/company-students`。
4. 当前端企业登录手机号未命中 `WT`、查询不到用户或查询不到岗位时，继续沿用原有企业审核状态分流：`auditStatus === 1` 进入审核中页，其他非通过状态进入企业审核填写页。
5. 学员登录流程不受影响。
6. 代码检查或构建通过；如无法执行，必须记录原因和剩余风险。
