# 20260614 实施与验证记录

## 1. 本轮实施范围

- 后端 APP 客服消息模块从 `com.huiyitech.message.controller.app` 迁移到 `com.huiyitech.app.message`
- 保留 `controller / controller.vo / service` 结构，保持原 APP 访问 URL 不变
- 新增 WebSocket 入站监听，支持学员端与企业教员端通过 `/infra/ws` 发送文本消息
- 保持现有历史查询逻辑不变，实时消息仅用于当前会话追加显示
- 前端聊天页接入 WebSocket，发送失败时回退现有 HTTP 发送
- H5 开发环境补充 WebSocket 代理能力
- 补充聊天图片、视频发送：媒体文件上传百度 BOS，消息表存储 BOS 地址，历史查询与实时消息统一展示

## 2. 关键代码改动

### 2.1 后端

- 迁移 APP 消息模块到 `com.huiyitech.app.message`
- 新增 `AppCustomerServiceMessageWebSocketListener`
  - 消息类型：`yj_customer_service_send`
  - 从 `WebSocketSession` 读取当前 `LoginUser`
  - 统一调用 `CustomerMessageService.sendRealtimeMessage(...)`
- `CustomerMessageServiceImpl`
  - 新增 `sendRealtimeMessage(LoginUser, Long, String)`
  - 学员端实时消息仍沿用原入库逻辑
  - 企业教员端实时消息仍沿用原会话绑定、消息入库、快照更新逻辑
  - 新消息入库后继续通过 `yj_customer_service_message` 向 MEMBER / ADMIN 广播
  - 新增百度 BOS 配置 `huiyitech.bos.baidu`
  - 在 `com.huiyitech.utils` 新增 `BaiduBosProperties`、`BaiduBosUtil`、`BaiduBosUploadResult`
  - 新增学员端、企业教员端媒体发送接口：上传文件到 BOS 后将 `message_type` 写入 `image` / `video`，`content` 写入 BOS 地址
  - 会话快照内容对媒体消息显示为 `[图片]`、`[视频]`，避免会话列表直接展示长地址

### 2.2 前端

- 新增 `src/services/customerServiceWebSocket.ts`
  - 使用 access token 连接 `/infra/ws?token=...`
  - 发送外层消息包：`{ type, content }`
  - 兼容后端外层 JSON + `content` 字符串化 JSON 的收包格式
- 调整 `src/pages/service/customer-service-chat.vue`
  - 页面进入时先走原历史查询
  - 查询完成后建立 WebSocket 连接
  - 当前会话收到实时消息后仅追加，不再全量刷新消息列表
  - 页面隐藏/卸载时关闭 WebSocket
  - WebSocket 发送失败时回退现有 HTTP 发送接口
  - 补齐图片发送：`uni.chooseImage` -> `uni.uploadFile` -> 入库消息追加
  - 补齐视频发送：`uni.chooseVideo` -> `uni.uploadFile` -> 入库消息追加
  - 图片消息支持预览；视频消息在聊天气泡内直接使用原生 `video` 播放
- 调整 `src/services/apiBase.ts`
  - H5 开发环境默认 APP 基址使用 `/yj-app-api`
- 调整 `vite.config.ts`
  - `/yj-app-api` 代理开启 `ws: true`

## 4. 当前结论

- 前后端 WebSocket 聊天链路代码已补齐
- 历史查询逻辑保留，实时消息只做当前会话追加
- 刷新或重新进入后，仍依赖现有历史查询接口回放消息
- 图片、视频消息现已进入正式链路：上传文件 -> BOS 存储 -> `yj_message_info` 写入 BOS 地址 -> WebSocket 广播 -> 聊天页展示
- 当前缺少的是真实运行态联调证据，不是已发现的代码链路缺口

## 6. 追加排查记录

- 现象：企业端进入客服中心时，`/app-api/yj/company-students` 返回 404，页面提示“学员列表加载失败”
- 根因：`FrontCustomerServiceSessionController` 迁移到 `com.huiyitech.app.message` 后，方法级映射仍是 `/yj/**`，但类上缺少其他 APP controller 一致的 `@RequestMapping("/app-api")`
- 修复：给 `FrontCustomerServiceSessionController` 补回 `@RequestMapping("/app-api")`，使实际暴露路径恢复为 `/app-api/yj/**`
