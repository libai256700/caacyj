- 任务ID：`T20260822`

- 创建日期：`2026-08-22`

- 合并状态：`不涉及独立分支合并`
- 分支处置：`不涉及独立分支删除`

## 2. 任务目标

1. 让未绑定企业的学生端用户点击“联系客服”后，能够直接进入客服对话，不再被“请先绑定企业，绑定成功后再联系客服”拦截。
2. 让该对话统一落到 tenant_id = 1 的企业客服会话，消息查询、发送和实时回传保持同一条真实链路。

## 3. 任务范围

- 包含：
- `code/develop/yunjikeji` 中未绑定企业入口的“联系客服”跳转链路
- `code/develop/yunjikeji-admin-server` 中学生端客服会话的 tenant 选择逻辑
- 现有客服会话、消息发送、实时消息广播的真实链路校正
- 不包含：
- 已绑定企业后的企业学员客服分流逻辑
- `uni_modules/**`

## 4. 统一原则

- 先读任务详情：阶段任务总表只做导航；真正实施前，必须先阅读对应任务详情。
- 计划启动门禁：只要 `01-验收标准.md` 未收口、阶段任务总表未补齐或当前任务没有任务详情，任何实施任务都不得进入 `进行中`。
- 正式验收承载位置：正式验收标准统一写到 `01-验收标准.md`；`00-任务计划.md` 只保留验收入口和状态门禁，不平行定义第二套正式验收标准。
- 未通过场景门禁：只要正式验收项仍有 `未通过`，不得把任务状态改为 `已完成`。
- 人工审核门禁：只有“独立验收通过 + 用户明确审核通过”同时满足后，才允许执行归档和状态回写。
