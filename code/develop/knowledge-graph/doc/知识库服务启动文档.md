# 知识库服务启动文档

## 1. 文档范围

本文说明 `E:\huiyitechworkspace\knowledge-graph` 在本机 Windows 环境中的启动、验证、接口调用和常见故障处理方式。

当前服务用于给 `E:\huiyitechworkspace\feixingxueyuan\code\develop\yunjikeji-admin-server` 的知识库管理模块提供知识库查询与新增文件导入能力。

## 2. 服务组成

| 服务 | 作用 | 默认地址 |
| --- | --- | --- |
| Neo4j | 图谱数据库 | `bolt://127.0.0.1:7687`、浏览器 `http://127.0.0.1:7474` |
| Flask 知识库 API | 对外提供查询、导入、健康检查接口 | `http://127.0.0.1:5001` |
| SQLite RAG 库 | 本地文本块和 RAG 数据 | `E:\huiyitechworkspace\knowledge-graph\rag_chunks.db` |
| Java 调用方 | 知识库管理模块调用知识库 API | `yunjikeji-admin-server` 已运行 |

## 3. 前置条件

### 3.1 Python 环境

本项目使用本机 Anaconda 的 `know-v2` 环境启动：

```powershell
D:\ProgramData\anaconda3\envs\know-v2\python.exe
```

如果本机 `know-v2` Python 路径变化，可以用环境变量覆盖：

```powershell
$env:KNOW_V2_PYTHON="D:\ProgramData\anaconda3\envs\know-v2\python.exe"
```

### 3.2 项目密码文件

Flask 服务启动时会读取：

```powershell
E:\huiyitechworkspace\knowledge-graph\neo4j\.neo4j_pass
```

## 4. 推荐启动方式

```powershell
D:\ProgramData\anaconda3\envs\know-v2\python.exe E:\huiyitechworkspace\knowledge-graph\scripts\start_know_v2_service.py
```

启动成功时会看到：

```text
Knowledge graph API is ready: http://127.0.0.1:5001
Query example: http://127.0.0.1:5001/api/ask?q=测试
File import endpoint: POST http://127.0.0.1:5001/api/files
```

## 5. 快速验证

### 5.1 健康检查

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:5001/api/health"
```

### 5.2 查询接口

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:5001/api/ask?q=测试"
```

### 5.3 新增文件接口

```powershell
curl.exe -X POST "http://127.0.0.1:5001/api/files" `
  -F "file=@E:\huiyitechworkspace\knowledge-graph\temp_smoke_import.txt" `
  -F "doc_name=启动文档测试文件" `
  -F "folder_hint=manual"
```

## 6. Java 侧对接配置

关键配置：

```yaml
yudao:
  ai:
    knowledge-graph:
      base-url: http://127.0.0.1:5001
      query-path: /api/ask
      file-import-path: /api/files
      legacy-file-import-path: /api/import/file
```
