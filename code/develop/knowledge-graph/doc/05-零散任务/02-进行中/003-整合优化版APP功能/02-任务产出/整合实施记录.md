## 3. 兼容策略

1. POST 使用 `application/json` 和 `user_query`；GET 继续接受 `q`，两者进入同一归一化逻辑并产生相同问题指纹。
2. 旧页面仍可调用 GET；新客户端优先 POST。POST 的 400/403/500 不会被误判为不支持 POST，只有 405 才回退 GET。
3. 默认启用目标真实存在的 `csa`、`bm25`、`dense`、`neo4j`、`web`；可用 `RAG_ALLOWED_RETRIEVAL_SOURCES` 进一步收窄。请求只允许使用“用户允许范围 ∩ 服务启用范围”。
4. `degraded`、`degraded_reasons` 同时位于响应顶层和 `stats`，保留旧消费者读取方式。
5. 不改变目标 `app.run(host="0.0.0.0", port=5001)`、CORS、密码文件、模型配置和真实数据路径。
6. 目标导入、Cypher、2D/3D CRUD、展示、统计、导出等路由经源码契约测试确认仍存在。
