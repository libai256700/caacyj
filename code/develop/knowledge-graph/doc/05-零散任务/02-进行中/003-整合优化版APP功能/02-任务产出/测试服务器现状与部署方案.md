4. 把 staged 文件先分别放到目标目录的临时文件名；全部就绪后以 `mv` 在同一文件系统内逐项原子替换到正式相对路径。Flask `debug=False`，替换过程中旧进程不会自动重载；五个文件全部替换完成后才允许重启。不得覆盖任何保护清单路径。
