## 2. 任务目标

1. 在本地 Neo4j `yunji-knowledge-graph` 容器中删除业务数据和云技科技资料。
2. 保留无人机理论题库、政策法规和无人机教材/书籍相关知识图谱内容，并形成可核对的备份、执行和验收记录。

## 3. 任务范围

- 包含：Neo4j 当前数据库只读预检、删除前备份、按来源和标签执行本地数据裁剪、删除后统计与样本验收、产出执行记录。
- 不包含：生产环境操作、远程数据库操作、知识抽取逻辑重构、RAG SQLite 内容清理、重新导入图谱、修改 `uni_modules/**`。

## 4. 统一原则

- 先读任务详情：阶段任务总表只做导航；真正实施前，必须先阅读对应任务详情。
- 计划启动门禁：只要 `01-验收标准.md` 未收口、阶段任务总表未补齐或当前任务没有任务详情，任何实施任务都不得进入 `进行中`。
- 正式验收承载位置：正式验收标准统一写到 `01-验收标准.md`；`00-任务计划.md` 只保留验收入口和状态门禁，不平行定义第二套正式验收标准。
- 删除前备份门禁：任何删除 Cypher 执行前，必须先完成 Neo4j dump 或等价可恢复备份，并记录备份路径。
- 未通过场景门禁：只要正式验收项仍有 `未通过`，不得把任务状态改为 `已完成`。
- 人工审核门禁：只有“独立验收通过 + 用户明确审核通过”同时满足后，才允许执行归档和状态回写。
