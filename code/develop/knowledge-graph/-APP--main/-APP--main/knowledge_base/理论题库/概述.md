1.无人机的英文缩写是     



A.UVS

B.UAS

C.UAV

参考答案：C

解析：UVS:  无人驾驶车辆系统（ Unmanned Vehicle System ）” 首字母缩写。这一术语通常泛指包括无人机（UAV）、无人地面车辆（UGV）、无人水下车辆（UUV）等在内的各类无人载具系统。

UAS:无人机系统（UAS： Unmanned Aircraft System）首字母缩写，是指无人机以及与其相关的遥控站（台）、任务载荷和控制链路等组成的系统

UAV:无人机（UAV： Unmanned Aerial Vehicle），是由控制站管理（包括远程操纵或自主飞行）的航空器。

20.无人机的伺服机构是（） 



A.电动

B.气动

C.油动

参考答案：A

解析：无人机的伺服机构主要用于控制无人机的飞行姿态和动作。电动伺服机构因其响应速度快、控制精度高、体积小、重量轻且易于维护，成为无人机的首选。

气动和油动伺服机构由于体积大、重量重、维护复杂等原因，不常用于无人机。





21.地面逆风起飞，滑跑距离（）



A.增长

B.减短

C.一样

参考答案：B

解析：在地面逆风起飞时，逆风会增加飞机的相对空速。相对空速的增加意味着飞机在相同的地速下可以获得更大的升力，从而减少起飞所需的滑跑距离。因此，逆风起飞会使滑跑距离减短。

28.将机场从北京搬到拉萨，对哪种飞机影响最大？ 



A.油动固定翼

B.电动固定翼

C.电动多旋翼

参考答案：A

解析：1、油动固定翼：依赖空气与燃料混合燃烧产生动力，高海拔空气稀薄会导致燃烧效率大幅下降，动力严重不足，影响最大。

2、电动固定翼：依赖电池供电，不受空气密度直接影响，但螺旋桨效率会降低，影响较小。

3、电动多旋翼：同样依赖电池，但多旋翼设计对气流变化更敏感，效率会有所下降，但影响小于油动飞机。

B.逆风

B.逆风

C.一样快

解析：1、地速定义：地速是飞机相对于地面的速度，由空速（飞机相对于空气的速度）和风速共同决定。

2、顺风情况：风速与飞机飞行方向相同，地速 = 空速 + 风速，因此地速更快。

3、逆风情况：风速与飞机飞行方向相反，地速 = 空速 - 风速，因此地速更慢。

4、结论：全马力飞行时，顺风的地速比逆风快。
