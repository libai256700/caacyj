35.航空器起飞着陆时使用跑道主要取决于:\[1分]

A.地面风向风速

B.机型

C.进场航迹与跑道中心延长线夹角的大小

参考答案：A

解析：

A航空器起降时优先选择逆风条件，这是航空动力学的基本要求。地面风向风速作为决定性因素主要体现在三个方面：

‌升力优化‌：逆风增加机翼相对气流速度，提升升力效率，缩短起飞滑跑距离；‌‌‌‌

‌安全性提升‌：逆风条件可降低航空器接地时的地速，减少着陆冲击力和滑跑距离；‌‌

‌动态适应性‌：风向风速实时变化，跑道选择需灵活匹配当前气象条件，而跑道坡度、机型需求等属于固定参数或次要因素。

B‌机型限制‌：不同机型对跑道长度、强度有特定要求，但在同一机场满足基本条件后，每次起降仍需优先考虑风向。

C进场航迹与跑道夹角‌：该参数影响降落时的航线修正，但属于操作层面的调整，并非跑道选择的根本依据。
