公司介绍
云技科技是一家聚焦人工智能与职业教育培训深度融合的科技企业，致力于以大模型、智能体、XR等前沿技术为核心，推动职业教育培训行业的数字化、智能化与场景化升级。公司面向国家新质生产力发展与高技能人才培养需求，重点服务无人机、机器人等战略性新兴产业领域，打造面向职业能力提升的智能培训解决方案。
公司围绕职业教育培训中的课程建设、实训教学、过程评价、能力诊断、个性化训练、考核认证与人才培养闭环等关键环节，构建“大模型驱动+智能体协同+行业知识融合”的技术体系，形成覆盖教学、练习、评测、反馈与优化的智能化服务能力。通过将行业知识、岗位标准与真实训练场景深度融合，云技科技能够为培训机构、院校及企业提供更精准、更高效、更具可解释性的教学支持与训练决策。
现阶段，公司重点布局无人机职业教育与执照培训赛道，依托AI智学体系，在CAAC培训、无人机专业知识理论教学、模拟实训、实操评估、专项能力画像及个性化就业辅导等场景开展应用，提供一体化产品赋能；未来将进一步拓展至机器人及智能装备职业培训领域，持续推动职业教育从传统经验式培训向数据驱动、模型驱动、智能决策驱动的新模式转型。云技科技坚持以技术赋能教育、以场景驱动创新，致力于成为职业教育智能化升级的重要推动者，为高素质技术技能人才培养和产业数字化转型提供坚实支撑。
