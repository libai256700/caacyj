四、CAAC执照基本认知
新学员可以直接选择视距内操控员或者超视距操控员。
考教员等级的学员须是已持超视距操控员执照且飞行满100小时。
定义：飞行半径500米，相对高度120米定义为视距内飞行。
特别说明：按照92部的文件执行视距内和超视距考取对应执照行驶对应权利。
（我们在引导学员的时候，只要不是就业需求的，就建议考视距内操控员，但是要说明白两者的差异性）
4、申请空域、飞行计划通过UOM系统申报，要求是执照编号。目前申报空域没有限制是超视距还是视距内，只要是CAAC执照就能申请空域，申报飞行计划。
5、92部做为一个必须要学习的文件。

   在云技培训考取的是民航局CAAC的执照。（CAAC的执照是国家颁发）
轻微型根据92部文件内容，可以免费考取理论培训合格证明。

CAAC（中国民航）—监管：中国航空器拥有者及驾驶员协会（AOPA）；中国地理信息产业协会（CAGIS）；中国航空运输协会(CATA）;
国家体育总局——中国航空运动协会（ASFC）
六、证件有效期——依据92部
按照现有的政策，CAAC的执照有效期是6年，每2年通过累计时间或6、4、证件有效期——依据92部
按照现有的政策，CAAC的执照有效期是6年，每2年通过累计时间或者参加实践考试更新证件（实践考试的所有客户）；
合格证有效期是两年，两年内飞行要满100小时，证件到期前3个月，通过APP申请更新合格证。

第二部分、CAAC执照考试内容
(1)理论考试
方式：机考模式（100题，单项选择三选一）
时间：120分钟
标准 :视距内驾驶员70分及以上；超视距驾驶员80分及以上
要求：日常学习模拟题测试分数视距内驾驶员理论80分以上，超视距驾驶员理论90分以上教员方可推荐考试。
(2)实践考试（全部通过，视为考试合格）
①综合问答
方式：机考模式 （10题，单项选择三选一）
时间：20分钟
标准 : 7分及以上
②实践飞行
视距内：GPS模式，核心动作包括起飞、悬停、水平360°慢转、水平8字飞行，误差标准：水平位移≤2米，高度≤1米，速度要求大于0.3米/秒小于3米/秒，8字航向切线夹角≤30°。
超视距：姿态模式，动作与视距内类似，但取消GPS位置修正，误差更严格：水平位移≤2米，垂直位移≤1米，航向偏差≤30°，速度要求大于0.3米/秒小于3米/秒。地面站预规划、重规划，一键返航。
教员：姿态模式，动作难度升级，包括顺/逆时针360°自旋、倒飞水平8字水、平位移≤2米，垂直位移≤1米，速度要求大于0.3米/秒小于3米/秒。航向偏差≤25°。
③地面站
仅超视距驾驶员
考试形式：电脑模拟
通过规则：三模块依次通过，任一模块失败即终止
模块1：航线预规划，要求：6分钟内按考官指令绘制完整航线。
模块2：航线重规划，场景：模拟突发 ——航点失效 / 新增临时禁飞区；要求：①10 秒内定位问题，②2 分钟内按考官要求完成修改（删 / 加航点、调高度 / 速度），③口头报备调整原因；
应急盲飞返航（约 2 分钟），场景：模拟数据链中断、GPS 丢失，仅看仪表（高度 / 速度 / 航向 / 距离）。要求：30 秒内完成：切换模式→安全返航 ，返航航线偏差 ≤±45°。
④教员口试
为考官与考试者的面对面问答、5 题、对3题及格，核心考察：专业知识讲解 + 教学方法 + 安全与应急教学能力。
口试五大必考模块：
1. 无人机系统与原理（专业深度）
多旋翼 飞行原理、姿态控制、GPS / 姿态模式区别
动力、飞控、云台、图传、链路、电池管理系统
典型故障：抖动、漂移、掉高、信号丢失、电机堵转
答题要求：讲原理 + 讲现象 + 讲判断方法
2. 法规与空域教学（合规教学）
CCAR-92 部、《无人驾驶航空器飞行管理暂行条例》
禁飞 / 限飞区、空域申请、实名登记、电子围栏
人口密集区、机场净空、夜间、超视距运行规则
答题要求：法条依据 + 教学要点 + 违规后果
3. 教学法与训练组织（核心能力）
课程设计：零基础→视距内→超视距教学计划
教学方法：如何纠正学员打杆过猛、姿态不稳、8 字漂移
学员评估：如何判断学员是否具备单飞能力
安全教学：风险点识别、课前检查、飞行监控
答题结构：原则 → 步骤 → 教学话术 → 安全提醒
4. 应急处置教学（2026 重点）
信号丢失、低电压、GPS 失效、单桨失效、避障失效、突风
教员职责：5 秒告警 → 接管 / 指导 → 安全返航 → 事后复盘
教学要求：会做 + 会讲 + 会教学员处置
直接不合格：不会应急、教学逻辑混乱
5. 实践考试标准讲解（教员必备）
视距内 / 超视距 实操标准、扣分点、及格线
悬停、自旋、8 字、精准降落 评判要点
如何规范带飞、纠正动作、安全监考
答题规范（必守）
必须站在教员角度：不只说 “怎么做”，更要说 “怎么教、怎么纠正、怎么防错”
结构清晰：
原则 / 法规
操作步骤
教学方法 / 话术
安全风险与提醒
第三部分：报考条件
年龄限制：视距内需满16周岁，超视距16-60周岁，教员需满18周岁。
健康与背景审查：矫正视力≥1.0，无色盲色弱及心脑血管疾病；需提供3-5年无犯罪记录证明（视距内和超视距及年，教员5年），并通过公安联网核查。
身体要求：矫正视力1.0以上，无色盲、色弱，
教员报名条件：取得机长驾驶证后，飞行记录本记录100小时以上飞行时间（需教官签字或盖章，合法空域内飞行有效）。
注意：有以下情形之一的，不得申请驾驶员合格证：患有心脏病、癫痫病、美尼尔氏症、眩晕症、癔病、震颤麻痹、精神病、痴呆以及影响肢体活动的神经系统疾病等妨碍安全飞行疾病的；吸食、注射毒品、长期服用依赖性精神药品成瘾尚未戒除的。
培训要求：必须通过民航局141部授权机构完成强制学时（视距内44小时，超视距56小时），学时由UOM平台实时核验，未达标者无法预约考试。
